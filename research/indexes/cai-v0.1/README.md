# 실험용 쿠싱 액티비티 인덱스 v0.1

**2023-12-29 기준 43.1 / 100.** 도로 교통량과 South STP 신고 유량을 고정 50:50으로 결합한 과거 자료의 활동 대리 지수입니다. 현재 쿠싱 활동·원유 물동량·유가 상승 확률을 나타내지 않습니다.

[대시보드](https://ls-crude.vercel.app/) · [동결 정의](definition.json) · [입력·계산·출력 해시](manifest.json) · [계산 프로그램](../../scripts/build_cai_v01.py) · [공개 데이터](../../../app/app/data/cai-public-view.json)

## 결과와 구성

| 자료 | 최신 성분 점수 | 비중 | 관측 기준일 | 정렬 기준일 |
| --- | ---: | ---: | --- | --- |
| TMAS AVC040 전체 차량 통행량 | 53.0 | 50% | 2023-12-29 | 2023-12-29 관측일 |
| Cushing South STP 월중 일최대 신고 방류유량 | 33.1 | 50% | 2023-11-30 | 2023-12-11 규제기관 접수일 |

최신 지수는 43.1, 직전 산출일인 2023-12-28은 41.1로 차이는 +2.0점입니다. 계산은 반올림 전 성분 점수를 결합한 뒤 한 자리로 반올림합니다. 화면의 성분 점수도 각각 반올림하므로 표시 숫자의 평균과 0.1 이내 차이가 날 수 있습니다.

**50은 각 자료가 기준 평균 수준일 때의 값**입니다. 43.1이 가동률 43.1%이거나 원유 가격 상승 확률 43.1%라는 뜻은 아닙니다. 차트의 날짜 선택은 과거 값을 확인하는 기능이며, 구성 카드에는 최신 산출일의 두 입력을 표시합니다.

## 고정 산식

```text
성분 z = (관측값 − 기준 평균) / 기준 모집단 표준편차
성분 점수 = 100 × (clip(z, −3, +3) + 3) / 6
CAI = 0.5 × 교통 점수 + 0.5 × 유량 점수
```

가중치는 사람이 정한 동일가중이며 최적화·머신러닝으로 구하지 않았습니다. 기존 `experiment.data.component_scores`와 `align_availability`를 재사용합니다. 새 분류기·목표값·가격 수익률은 계산하지 않습니다.

정규화 기준은 **2015-01-02~2020-12-23**입니다. 기존 교통·유량 회고 실험과 척도를 맞추기 위해 그 실험의 고정 기준을 재사용했습니다. 기존 5거래일 학습 경계 규칙 때문에 마지막 기준일은 12월 23일입니다. 활동지수 자체에 미래 5일의 정답이 필요하다는 뜻은 아닙니다.

| 기준 통계 | 교통 | 유량 |
| --- | ---: | ---: |
| 유효 기준 거래일 수 | 1,165 | 1,000 |
| 평균 | 6681.130472103005 | 2.050207 |
| 모집단 표준편차 | 1076.635700246699 | 0.7930275796912741 |

유량의 1,000일은 월별 신고값을 유효기간 안에서 재사용한 일수입니다. 독립 월별 관측 1,000건이 아닙니다. 원자료 단위는 교통 차량/일, 유량 MGD(백만 갤런/일)이며 단위가 다른 원값을 직접 합산하지 않습니다.

## 시간·결측 규칙

- Yahoo CL=F CSV에서 2015–2023 **날짜 열만** 사용합니다. 가격값·수익률·정답은 지수 계산에 사용하지 않습니다.
- 교통은 관측일이 같은 날에만 사용합니다. 관측일은 당시 외부 공개 시점을 입증하지 않습니다.
- 유량은 규제기관 접수일 이후 최대 62일까지 재사용합니다. 접수일은 최초 공개일이 아닙니다. 2023년 12월 유량은 접수가 2024-01-08이므로 마지막 지수에 사용하지 않습니다.
- 둘 중 하나라도 빠지면 그 날짜의 CAI는 `null`입니다. 0으로 채우거나 한 성분에 100%를 주지 않습니다. 표준편차가 0인 성분은 기존 함수의 중립값 50 규칙을 따릅니다.
- 거래일 캘린더 2,262일 중 **유효 1,003일·결측 1,259일**입니다. 유효 첫날은 2017-01-05입니다. 2017년 234일, 2018년 251일, 2019년 246일, 2020년 22일, 2023년 250일이며 2021–2022년은 입력 공백입니다. 차트는 결측 구간을 연결하지 않습니다.
- 과거 자료를 현재 기준으로 다시 계산한 회고 지수입니다. 개발 기준 통계가 만들어지기 전의 과거 점수를 당시 실시간 산출값으로 해석하지 않습니다.

## 자료와 한계

자료는 기존 해시 고정 교통·DMR 입력을 사용합니다. 교통은 전체 차량 수이며 원유 운송 차량만 센 것이 아닙니다. South STP 유량은 도시 처리시설의 신고 자료이며 강수·유입수·처리·신고 관행의 영향을 받습니다. 계절·요일·강수 영향을 분리한 지수는 아닙니다.

성찬님의 숙박세·사용세·공항 수신 자료는 원문·시점 검토 중이며 v0.1에 넣지 않았습니다. 현재 기준 활동지수나 검증된 예측모델로 승격하지 않습니다. 기존 2023년 WTI 비교 결과는 연구 기록의 고정 회고 실험으로 유지하고, 이 지수의 독립 예측력 검증으로 승격하지 않습니다.

공개 JSON은 `mode: RETROSPECTIVE`와 기준 분포·관측 날짜를 명시합니다. 모르는 정확한 `observed_at`·최초 `available_at` 시각은 `null`로 둡니다. 현재 관측 모드의 기존 시점 검증 요건은 그대로 유지합니다. 예측 확률과 독립 평가 지표는 비워 둡니다.

## 재현

저장소 루트의 기존 연구 환경과 해시가 일치하는 입력 파일이 필요합니다. 설치·입력 확보는 [공동 작업 안내](../../../docs/cai/TEAM_START_HERE.md)를 따릅니다. 원문·입력 CSV·개별 성분 시계열은 이번 공개 export에 추가하지 않습니다.

```sh
research/.venv/bin/python research/scripts/build_cai_v01.py --check
research/.venv/bin/python -m pytest research/tests/test_cai_v01.py -q
```

`--check`는 저장된 계산시각을 유지해 공개 JSON·명세를 재생성하여 비교합니다. 계산 코드·입력·정의 해시와 환경 버전이 명세에 남습니다. 원자료 다운로드, 모델 학습, OOS 값 사용은 없습니다. 실제 자료·산식을 갱신하려면 새 버전을 만들고 지수·이력·구성값을 함께 검증합니다. 단순 빌드나 웹 요청에서 계산을 다시 하지 않습니다.
