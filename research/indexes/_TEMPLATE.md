# 지수 정의/실행 영수증 — TEMPLATE (미구축)

실제 입력이 생긴 후 <candidate_id>/README.md로 복사합니다. 값·수치·실행 성공을 미리 채우지 않습니다.

## 사전 정의

| 항목 | 값 |
| --- | --- |
| 후보 ID / 카드 경로 | 미정 |
| 버전 / 작성자 / 검토자 | 미정 |
| 구성하려는 활동·WTI 연결 가설 | 미정 |
| 원천 필드 → 산식 / 가중치 | 미정 |
| 원천/지수 단위·빈도·지역·고정 바스켓 | 미정 |
| 집계·분모·기준기간·정규화·워밍업 | 미정 |
| 결측/실제 0/이상치·개정 처리 | 미정 |
| observed_at / available_at / timezone | 미확인 |
| 선택/검증 기간·OOS 노출·동결시각 | 미확인 |
| WTI 타깃·lag·event/placebo·전체 검정군 | 미정 |
| KEEP/KILL/PARK 사전 판단 기준 | 미정 |

## 실행 manifest (실행마다 추가, 이전 기록 보존)

| 역할 | 저장소 상대 경로 / 재취득 방법 | SHA-256 | 기간 / 행 수 | 시각·빈티지·권한 |
| --- | --- | --- | --- | --- |

원본 입력, 정제본, 지수 출력, WTI 입력을 구별해 모두 기록합니다. 표는 현재 비어 있습니다. 원본이 없으면 실행하지 않고 후보의 blocker를 갱신합니다. 데이터·키 자체를 여기에 붙이지 않습니다.

| 실행 항목 | 값 |
| --- | --- |
| run ID / 실행시각(시간대 포함) / 실행자 | 미실행 |
| 작업 디렉터리 / 정확한 명령 | 미실행 |
| 실제 스크립트/노트북 경로 | 미작성 |
| Git revision / dirty 여부 / 코드 hash | 미기록 |
| Python 및 의존성 버전 / 필요한 환경변수 이름(값 제외) | 미기록 |
| 반환 코드 / 오류·재시도 / 로그 경로 | 미실행 |
| 품질·커버리지 표 / 시계열 그림 | 미생성 |
| 검정 전체 표 / lag·event·placebo 결과 또는 미실행 이유 | 미생성 |
| 주장할 수 있는 것 / 주장할 수 없는 것 | 미검증 |
| 다른 팀원의 입력 접근 / 재현 명령·시각·결과 | 미검토 |
| 판정·수정 내역 / 후보 카드 반영 | 미검토 |

재현 가능한 로컬 출력과 제3자/팀 재현은 다릅니다. 동료가 동일 입력에 접근하지 못하거나 명령을 실행하지 않았다면 팀 재현을 완료로 표시하지 않습니다.
