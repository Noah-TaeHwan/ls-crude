# data

여기에는 **돌아가는 시드**와 **팀원이 통째로 넣은 랩**만 둡니다. 웹 조사 원문은 [`../gathering/raw/`](../gathering/raw/README.md).

| 칸 | 무엇인가 | 깃 |
| --- | --- | --- |
| `event_calendar.csv` | Oil Slice 시드 헤드라인 | 올림 |
| `pizza/` | 대안 데이터 후보 시계열·뉴스 시드 (사람이 고른 것) | 시드만 |
| `pizza/raw/` | 후보 원본 덤프 | 안 올림 |
| `raw/`, `processed/` | Yahoo 빌드 산출 | 안 올림 |
| 팀원 드롭 | 코드·노트북이 있는 랩 폴더 | 폴더 이름 그대로. **gathering으로 이사하지 않음** |

## 팀원 드롭 vs 후보 vs 수집

- **후보** (`pizza/`): 크립토의 뭐 × 뉴스의 무슨, 시계열 시드. 오태환 조사.
- **팀원 드롭**: 손성찬(또는 동료)이 넣은 랩. 지금 깃에 파일이 없어도, 다시 넣을 위치는 **이 폴더 아래 원래 이름**입니다. `gathering/`으로 이사하지 않습니다.
- **수집** (`../gathering/`): AI/사람 조사 덤프와 한 장 노트.

| 드롭 폴더 | 무엇 |
| --- | --- |
| `TTS scrapper/` | TTS·팩터 랩. 코드가 빠져 있어도 자리는 여기 |
| `iran whale tracker/` | 이란 고래 추적 랩. 동일 |

zip·parquet·큰 CSV는 커밋하지 않습니다. 규칙은 [`../INTAKE.md`](../INTAKE.md).
