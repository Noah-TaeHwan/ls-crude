# ALT-20260908-05 — Cushing Pipeline Apportionment Notice Scope

## 1. 후보와 가설

| field | value |
| --- | --- |
| thesis | Cushing 연결 crude pipeline 운영자의 allocation·apportionment 공지가 실제 운송 제약을 직접 설명할 수 있는가 |
| activity | 서비스월, 방향, 가용용량 감축, allocation/apportionment 비율, 공지시각 |
| falsification | 공개 역사 공지에서 Cushing 연결성·방향·시점·비율을 구분할 수 없으면 이 데이터 경로를 종료 |
| legacy_ref | 091-E. 도시 프록시가 아닌 first-party 운영 신호의 접근 감사 |

## 2. 출처와 실제 확인

공식 [Keystone tariff](https://www.tcenergy.com/siteassets/pdfs/oils-and-liquids/keystone-shipper-info/ferc/tc-keystone-ltd-ferc-5.5.0-rules-and-regulations-tariff.pdf)는 Customer Portal의 Notice of Shipment와 `Mid-Month Apportionment` 절차를 명시한다. 이는 절차·가능성을 확인한 실제 표본이다.

그러나 이 파일은 월별 사건·배정률 데이터가 아니다. 고객 포털은 기존 고객/shipper 범위이며, 로그인·신청·우회는 하지 않았다. FERC eTariff도 tariff·개정 파일 시스템이지 표준화된 crude apportionment 이벤트 피드로 확인하지 않았다.

## 3. 지수·검정

**NOT_RUN.** 실제 공지 행·최초 게시시각·서비스월·방향·allocation %가 없으므로 재고·기간스프레드·WTI 상관을 계산하지 않는다.
