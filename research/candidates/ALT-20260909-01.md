## 신호 스케치 (미구현)

Signal A: DustShock ≫ 0 + 교란 존재 → 허리케인 프리미엄 과대 가능 (숏 크랙 / 근월 대비 원월).
Signal B: DustShock ≪ 0 + 따뜻한 SST + 낮은 전단 + 파 + 걸프 경로 → 셧인 전 대피 구간에서 리스크 과소 가능.

회사는 상륙 전에 생산을 줄인다. 상륙일 WTI가 타깃이 아니다.

검증 배터리(계획): block bootstrap, HAC, event study, 연도 안정성, 시즌 플레이시보, 무작위 날짜 플레이시보. OOS에서 파라미터 금지.
