## 코드에서 확인해 고친 것

1. **가중치 학습 실패를 성공으로 표시하던 문제.** 원본은 내부 학습 20행·검증 10행에 못 미치면 모든 가중치의 목적함수를 `1e6`으로 반환합니다. 상위 탐색은 초기값 50:50을 그대로 저장하고 `RUN`으로 표시했습니다. 수정본은 `BLOCKED_INSUFFICIENT_INNER_SPLIT`을 반환하고 해당 가중치·성능·비교 차이를 만들지 않습니다. 유효 목적함수가 없거나 내부 학습 정답이 한 종류뿐인 경우도 구분해 차단합니다. 원래 최소 기준을 낮추지 않았습니다.
2. **정답의 종료일 검사.** `label_end`를 필수로 받고, 학습 행의 관측일뿐 아니라 정답을 계산하는 마지막 날짜도 학습 종료일 이내인지 검사합니다. 내부 가중치 학습도 같은 경계를 지킵니다. 원본의 6월 학습행은 7월 가격으로 정답을 만들기 때문에 ‘6월 말까지의 자료로 학습’이라는 엄격한 해석과 맞지 않았습니다. 수정본 월별 행은 월말로 표시하며, 이 정렬이 실제 공개시점을 입증하는 것은 아닙니다.
3. **적격성과 실제 실행 상태 일치.** 성분의 관측 수·변동성은 학습 행만으로 확인합니다. 정답 경계 적용 후 원래 월별 일정에 남는 학습 행은 11개이므로, 성분 최소 12개 조건도 통과하지 못합니다. 이 경우 CAI 비교를 완료로 표시하지 않습니다. 기준선 계산 가능 여부와 CAI 성분·가중치 학습 가능 여부는 별도입니다.
4. **검사 자체의 실측 실행 제거.** 기존 `self-test`는 2024–2025년 실제 내장 실험을 실행했습니다. 수정본은 합성 입력만 사용하며 정상 학습·표본 부족 차단·정답 경계를 검사합니다. 월별 결과에 5거래일 진단을 붙이지 않고, 기존 출력 폴더 재사용도 거부합니다.

50:50 문제는 **CAI 조합 가중치를 최적화하지 못했다는 뜻**입니다. 원본의 다른 로지스틱 분류모델 실행 전체가 없었다는 뜻은 아닙니다. 메모의 모델 성능값은 성찬님 보고로 보존하며, 수정본의 성능으로 재사용하지 않습니다.

## 바로 실행할 수 있는 검사

저장소 루트에서 기존 연구 가상환경을 사용합니다. 새 패키지 추가는 없습니다(`numpy`, `pandas`, `scikit-learn`, 테스트용 `pytest`). 로컬 태환 환경은 `research/.venv/bin/python`, 성찬님은 이미 설치한 `research/.venv-share/bin/python` 또는 Windows의 `research\.venv-share\Scripts\python.exe`를 사용하면 됩니다.

```sh
research/.venv/bin/python research/experiments/cai/seongchan/monthly_engine.py self-test
research/.venv/bin/python -m pytest research/tests/test_seongchan_review.py -q
```

예상 출력은 `data_origin: SYNTHETIC`, `embedded_data_checked: false`, `all_pass: true`입니다. 검사 통과는 원문 수치·실제 성능의 검증이 아닙니다.

사용자 CSV를 검사할 때는 `date`(판단 기준일), `label_end`(정답에 필요한 마지막 날), 이진 target, 지정 성분/시장정보 열이 필요합니다. 월말·접수일·파일 작성일을 실제 공개일로 바꾸어 채우지 않습니다. 기존 일별 공통 프로그램의 CLI·입력 규격을 이 실험 엔진으로 교체하지 않습니다.

## 실제 월별 재실행은 별도 검토

기존 일별 공통 규약은 2015–2023, 학습 종료 2020-12-31, Yahoo CL=F, 다음 5거래일 방향, seed 7입니다. 수신본은 월별 EIA 현물, 다음 달 방향, 2024년 학습/2025년 평가, seed 42입니다.

이 작업에서는 `official-5-11-16`과 실측 `export-all`을 실행하지 않았습니다. 2024년 이후는 프로젝트의 보호 검정 구간이므로, 외부 월별 재현의 별도 범위·시점 규약을 정하기 전에는 재학습하거나 가중치 기준을 바꾸지 않습니다. 성찬님 메모에 이미 해당 기간의 성능이 보고됐다는 노출 사실은 보존합니다. 이를 미열람 최종 OOS로 주장하지 않습니다.

## 성찬님께 필요한 자료

- 숙박세·사용세의 공식 원본 PDF, 해당 표 페이지, 파일 SHA-256. 관측월/보고월/수령월을 구분한 메모와 수정된 값이 있으면 그 근거.
- 공항 4행의 원표와 항목별 관측월. 판매세 충돌 행의 원표 두 버전과 선택/제외 근거.
- 기존 실행의 `ALL_IN_ONE_RESULT.json`, `model_run/result.json`, `model_comparison.csv`, `weights.csv`와 환경 버전. 이 결과는 원본 코드 실행본이라는 표시를 유지.

시청의 옛 PDF 경로 일부가 현재 새 홈페이지 HTML로 이동하므로 원본 파일이 있으면 대조에 도움이 됩니다. 파일을 받으면 원문→전처리 값→시점·기간→실험 적격성 순서로 검토합니다. 원본을 보기 전까지 준비 입력 수는 **2개**, 성찬님 **3개 후보는 제출 검토 중**입니다. 새 지수값·성과 수치를 생성하지 않았습니다.
