# 078 — Korea Freight & Port Fuel Pulse

**상태**: ⏸️ **HOLD / untested**  
**Oil Pizza 가중치**: `0.0`

## 가설

도로 상업차량 흐름과 산업항만의 선박·화물 활동이 동시에 급변하면 국내 경유·벙커·석유화학 물류의 운영 레짐 변화일 수 있다.

```text
차종별 고속도로 통행 변화  +  울산·여수·부산 등 산업항만 활동 변화
→ 국내 연료·물류 압력의 공개 집계 프록시
→ 한국 정제품/해운 연료 맥락 또는 변동성 반증
```

## 두 다리 — 섞기 전에 각각 반증

1. **Freight leg**: 한국도로공사 톨게이트 차종별 통행량. 차종 코드가 실제 대형 화물차를 뜻하는지 원문 사양으로 검증한 뒤에만 사용한다.
2. **Port leg**: 해양수산부의 입출항 선박·총톤수 및 항만 화물처리 실적. 원유·정제품·석유화학을 구분할 수 있는 항목만 별도 신호로 쓴다.

두 다리 모두 IS/OOS에서 같은 경제적 방향을 재현하지 못하면 합성지수를 만들지 않는다. ‘항만이 바쁘다’는 말만으로 원유 방향을 부여하지 않는다.

## 검정 설계와 한계

- 우선 타깃: 국내 경유가격·한국 정제품/해운 연료 관련 지표의 미래 변동성. WTI는 보조 반증이다.
- 주·월별 공식 공개일을 기준으로 IS 2015–2023 / OOS 2024+를 나눈다.
- 현재는 API·파일 후보만 확인했다. 차종 정의, 역사 연속성, 첫 공개일, 개정 이력을 수집하지 않아 수치·상관은 없다.

## 데이터 경계

공개 집계 교통·항만 통계만 사용한다. AIS 개별 선박 추적, 운전자·화주·차량 위치, 항만 출입기록을 수집하지 않는다.
