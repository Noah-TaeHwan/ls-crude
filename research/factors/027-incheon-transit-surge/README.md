# 027 — Incheon Transit Surge (ITS)

**상태**: ⏸️ **HOLD / aviation-demand context**  
**Oil Pizza 가중치**: `0.0`

## 원안

인천공항의 중국 관련 여객 또는 환승 수요 급증이 동북아 항공유 수요와 기대-실적 괴리를 보여 주고 WTI 변동성을 높일 수 있다는 가설이다.

## 먼저 바로잡을 것

인천공항은 전체·노선·여객·화물의 공개 통계를 제공하지만, 현재 확인한 일반 공개 표는 중국 **국적** 승객이나 중국발 **환승객**을 자동으로 분리하는 시계열이라는 보장이 없다. 또한 2026년 정책은 중국 등을 포함한 단체관광객의 비자 **수수료 면제** 연장이지 일반 중국인 무비자 재개라는 뜻이 아니다. 출처 없는 2026년 여객수·WTI 반응 사례는 기록하지 않는다.

## 테스트 가능한 축

```text
사전 고정 계절기대치 대비
인천 국제여객·중국 노선 여객·항공화물 서프라이즈
→ 다음 21거래일 WTI 실현변동성
```

월간 통계는 다음 달 영업일 기준 5일 뒤 공개된다. 따라서 실시간 1–2주 경보가 아니라 **월간 항공 수요 nowcast**다. 단일 공항의 실제 연료 수요 규모가 글로벌 원유 변동성을 움직인다고 가정하지 않으며, 먼저 반증용 인샘플 테스트가 필요하다.

## 데이터 경계

- 공개된 공항·관광공사 집계만 사용한다.
- 개인 여권 국적, 예약, 환승 경로, 항공권 구매·수하물 데이터를 수집하지 않는다.
- China route(노선)와 Chinese passenger(국적)는 같은 변수가 아니다.
