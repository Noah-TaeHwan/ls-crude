# 024 — Chuseok Effect (CE)

**상태**: ⏸️ **HOLD / domestic-demand context**  
**Oil Pizza 가중치**: `0.0`

## 원안

추석 직전의 귀성 이동·항공·화물·정유 운영이 한국 내 연료 수요와 불확실성을 높여 WTI 변동성을 증폭할 수 있다는 가설이다.

## 냉정한 구조

추석 날짜는 사전에 완전히 알려진 달력 사건이다. 따라서 ‘연휴가 있다’ 자체는 국제 원유시장에 새 정보가 아니다. 2015–2023의 추석 사건은 9개뿐이므로 독립적인 WTI 변동성 알파를 검정할 표본도 부족하다.

살아 있는 질문은 달력 효과가 아니라 **사전 기대치 대비 공개 집계 수요의 서프라이즈**다.

```text
사전 고정 계절기대치 대비
고속도로·공항·공개 화물 통계의 이탈
  → 한국 국내 운송·항공 수요 맥락
  → 미래 WTI 변동성 (반증용 탐색)
```

## 허용 입력과 경계

| 입력 | 상태 | 경계 |
| --- | --- | --- |
| 인천공항 집계 여객·화물 | 월간 공개 경로 확인 | 실제 월말 공개 뒤에만 사용 |
| 한국도로공사 집계 교통량 | 공개 API 후보 | 휴일 기준·역사·공개시점 확인 전 미수집 |
| 정유 가동률 | KNOC 공개 자료는 연간 확인 | 추석 직전 일별/주별 가동률로 과장 금지 |
| 온라인 쇼핑 주문 | 제외 | Coupang 등 개인·플랫폼 주문 수집 금지 |

## 결론

024는 한국 소비·교통 대시보드에서 재미있는 계절 레이어다. 그러나 현재는 WTI 변동성 팩터가 아니다. 추석이라는 달력 자체로 임계값을 만들거나 수익률을 주장하지 않는다.
