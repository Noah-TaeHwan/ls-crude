# 021 KHI — 자료 수집 명세

이 폴더에는 재사용 가능한 **출처 목록과 수집 규칙만** 저장한다. API 원본 응답, API 키, 대형 시계열은 저장하지 않는다.

## 공식 무료 입력

1. KAMIS Open API에서 `일별 가격`을 조회한다. API 문서 예시의 `p_cert_key`, `p_cert_id`는 발급받은 개인/조직 자격증명이며 저장소에 넣지 않는다.
2. 배추·무·마늘·고춧가루별로 정확한 품목·품종·등급·단위·유통채널 코드를 먼저 고정한다.
3. 각 품목의 실제 공개 가능 시각, 역사 범위, 개정 정책과 저장·재배포 조건을 문서화한다. 확인 전에는 백테스트하지 않는다.

## 보관 경로

| 종류 | 경로 | GitHub |
| --- | --- | --- |
| API 원본 응답 | `research/gathering/raw/YYYY-MM-DD-kamis-khi/` | 금지 (`.gitignore`) |
| 수집 메타데이터·짧은 수동 시드 | 이 팩터 폴더 또는 `research/data/pizza/` | 라이선스 확인 후만 |
| 출처·라이선스·지연 기록 | `research/gathering/sources/REGISTRY.md` 및 이 폴더 | 허용 |

## 최소 레코드 스키마

```text
available_at_utc, source_date, item_code, item_name, variety,
grade, unit, channel, region, price_krw, source_url, retrieved_at_utc
```

`source_date`가 아니라 `available_at_utc`가 분석 정렬의 기준이다. 한국 공휴일·주말·휴장일에는 다음 이용 가능한 관측 시점으로 처리하고, 원유 일봉과 같은 날 종가를 미리 아는 방식으로 맞추지 않는다.

## KHI v0 (아직 계산하지 않음)

각 품목의 단위와 계절성을 맞춘 뒤, 동일 달/동일 채널 기준 가격 변화를 표준화해 중앙값으로 묶는 방안만 기록한다. 구성품·가중치·결측 규칙은 실제 역사와 공개시점이 확인된 뒤 **인샘플에서만** 동결한다. 지금은 지수 수치·상관계수·거래 임계값이 없다.

## 금지된 수집

- 온라인 마트 페이지의 무단 스크래핑 또는 가격 추적
- 개인 구매 영수증·주문·멤버십·위치 데이터 수집
- KAMIS 키, 쿠키, 계정 정보의 커밋
- 현재 API의 수정된 과거값을 당시 이용 가능했던 값으로 가정하는 백테스트
