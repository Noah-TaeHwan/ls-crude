# 021 — Kimchi Heat Index (KHI)

**상태**: 🧊 **IDEA ARCHIVED / HOLD**  
**Oil Pizza 가중치**: `0.0`  
**역할**: 한국 식탁 물가·기후 스트레스의 밈형 모니터. WTI 방향 또는 변동성 거래 신호가 아니다.

> “김치가 매워지면, 식탁의 인플레이션도 매워진다.”

## 먼저 결론

`김치 가격 상승 → 며칠 뒤 원유 상승`은 현재 근거 없는 서사이며, 이 카드에서는 **유가 알파 가설로 채택하지 않는다**. 김치 원재료 가격은 작황·날씨·계절성·수입·유통·프로모션의 영향을 크게 받는다. 원유가 일부 비용 경로에 들어가더라도 이 가격들이 원유를 앞서서 알려 준다는 인과 경로는 확인되지 않았다.

KHI는 한국의 식품 체감물가와 농산물 공급 스트레스를 한눈에 보는 공개 데이터 대시보드 후보로만 보존한다. ‘피자 인덱스’처럼 기억하기 좋은 서사는 남기되, 원유 포지션에는 쓰지 않는다.

초기 바스켓은 공개 가격 정의가 확인되는 품목만 쓴다.

| 구성 | 이유 | 수집 상태 |
| --- | --- | --- |
| 배추 | 김치의 핵심 원재료·작황 민감 | KAMIS API 품목 코드·역사 확인 전 |
| 무 | 주요 김장 재료·계절성 확인용 | KAMIS API 품목 코드·역사 확인 전 |

| 고춧가루 | 양념 비용·수입/작황 교란 확인용 | KAMIS API 품목 코드·역사 확인 전 |

소금, 완제품 김치, 특정 마트 판매가는 초기 지수에서 제외한다. 품질·용량·할인·제조사 차이가 커서 일관된 공개 시계열이 확인되기 전에는 섞지 않는다.

## 허용 자료와 경계

- 공식 KAMIS/aT의 집계형 농산물 가격 API와 공개 가격 페이지 만 사용한다.
- Coupang·마켓컬리·이마트 등 소매 웹사이트를 자동 수집하지 않는다.
- 개인 영수증, 고객 주문, 소셜미디어 개인 게시물, 위치 정보는 수집하지 않는다.
- API 키와 원본 응답은 GitHub에 저장하지 않는다. 원본은 `research/gathering/raw/`의 gitignored 경로에만 둔다.

수집 입력의 출처·URL·재사용 경계는 [sources.csv](sources.csv), 실제 수집·정렬 명세는 [COLLECTION.md](COLLECTION.md)에 있다.
