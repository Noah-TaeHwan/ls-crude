# 065 — War-Room Coffee Index

**상태**: ⛔ **REJECTED — 심야 커피 수요의 공개 장기 패널이 없다.**  
**별칭**: *When the Coffee Never Stops*  
**Oil Pizza 가중치**: `0.0`

## 가설

휴스턴·런던·싱가포르의 에너지 트레이딩 지구에서 심야 카페 이용이 비정상적으로 증가하면, 비상 대응·야간 딜·운영 스트레스의 공개 행동 흔적일 수 있다는 가설이다.

## 수집·테스트 결과

현재 카페 API·지도 서비스는 매장별 과거 시간대 매출·방문객을 공개하지 않는다. `045 Iced Americano`의 Starbucks 분기 총매출은 심야·트레이딩 지구·에너지 종사자를 측정하지 않고, WTI 변동성에서 IS/OOS `+0.512/-0.511`로 이미 부호 반전했다. 이를 재활용하지 않는다.

**IS/OOS 가격 검정: 미실행.** 원래의 ‘심야 커피’ 신호가 없으므로 숫자를 만들지 않는다.

재개에는 도시권 익명 시간대별 카페 결제/방문 합계가 필요하며, 매장·고객·직원 단위 데이터는 허용하지 않는다. [감사 노트](../../gathering/notes/2026-09-07-pizza-style-five-factor-audit.md).
