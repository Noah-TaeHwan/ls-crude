# 008 — Hyperliquid Capital Flow (온체인 자금흐름)

**상태**: ⏸️ **HOLD — 설명적 모니터링만**. Hyperliquid 고유 팩터·MENA 조기경보·Oil Pizza 입력 후보는 아니다.
**가능한 역할**: 넓은 크립토 레버리지 레짐의 화면상 맥락. WTI 신호·가중치로 사용 금지.
**Oil Pizza 가중치**: `0.0`
**변동성 기준 (2026-09-03)**: 미래 5거래일 WTI 실현변동성. 2023 이후 자료·귀속 문제로 미검증이며 monitor only.

## 결론

008은 002와 같은 구조적 한계가 있다. 공개 온체인 흐름은 볼 수 있어도, **누가 왜 입금했는지**는 알 수 없다.

| 항목 | 002 Whale | 008 Hyperliquid |
| --- | --- | --- |
| 관측값 | 대형 크립토 거래·이동 | OI·펀딩·거래량·브릿지 흐름 |
| 주장하고 싶었던 귀속 | 고래가 유가 정보를 안다 | 유입이 MENA 탈출 자금이다 |
| 확인 불가한 것 | 보유자·의도·정보 우위 | 국적·의도·지정학적 동기 |
| 더 일반적인 설명 | 위험선호/유동성 | 크립토 레버리지 레짐 |

따라서 Hyperliquid 유입을 중동 자금 이탈·제재 회피·유가 선행정보로 해석하지 않는다. 주소 태깅, 개인·OTC·믹서 추적을 통해 그 귀속을 보완하려는 시도도 범위 밖이다.

## 008이 002보다 나은 점과 남는 한계

008의 타깃을 WTI 방향이 아니라 **단기 시장 스트레스·유동성 레짐**으로 둔 점은 더 정직하다. 그러나 좋은 타깃 설정만으로 표본과 고유성이 생기지는 않는다.

| 쟁점 | 판정 |
| --- | --- |
| 메커니즘 | 약함. 크립토 레버리지 레짐과 유가 스트레스가 동행할 수는 있으나, 독립적 전달경로는 미검증. |
| 역사 | 부적격. Hyperliquid 자료는 2015–2023 인샘플 전체를 물리적으로 충족하지 못한다. |
| 고유 알파 | 미확인. 더 긴 역사를 가진 광범위 거래소·시장 단위 OI/펀딩과 비교해 Hyperliquid이 우월할 이유가 없다. |
| MENA 귀속 | 불가. 공개 데이터로 출신 지역·목적을 확인할 수 없다. |
| 현재 처리 | 설명적 모니터링만. 백테스트·가중치·실험 카드 없음. |

최근 2–3년 정도의 Hyperliquid 관찰치를 2015–2023 후보 선정 규칙 대신 쓰지 않는다. 약 500 거래일의 짧은 구간과 드문 지정학 이벤트만으로는 반복 검증도 부족하다.

## 모니터링에서 볼 수 있는 것 / 볼 수 없는 것

| 볼 수 있는 것 | 해석 금지 |

| 시장 전반의 레버리지 축적·청산 가능성 | WTI 방향의 선행 신호 |

이 화면은 경보등이 아니라 맥락 패널이다. 수치가 움직여도 Oil Pizza는 `0.0`이다.

## 재개 조건

Hyperliquid 자체를 되살리는 조건은 없다. 크립토 레버리지 레짐을 별도 후보로 검토하려면 다음을 모두 새로 충족해야 한다.

- [ ] Hyperliquid이 아닌 더 넓은 시장 단위의 적법한 집계 OI·펀딩 시계열이 2015–2023에 존재한다.
- [ ] 실제 공개시점·개정·거래소 장애를 고정한 시계열을 만든다.
- [ ] BTC/ETH 변동성, 달러, VIX 등 공통 요인을 사전 지정해 통제한 뒤 증분 설명력을 시험한다.
- [ ] 플랫폼별 후보를 비교해 고르는 것이 아니라, 비교 규칙을 먼저 동결한다.
- [ ] 이후 한 번의 2024년 이후 아웃샘플에서만 확인한다.

그 전까지 008은 팩터가 아니라 관찰 기록이다.
