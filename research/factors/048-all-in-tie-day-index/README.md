# 048 — All-In Tie Day Index (ATDI)

**상태**: 🎙️ **MEME / MONITOR ONLY** — 공개 방송의 복장은 원유 선행 알파가 아니다.  
**별칭**: *When the Bros Wear Ties*  
**Oil Pizza 가중치**: `0.0`

확장 탐색·CEO 비교·블라인드 라벨 계약은 팩터가 아닌 [Side Quest 001](../../side-quests/001-executive-formality-asset-regimes.md)에서 별도로 관리한다.

## 질문

평소 캐주얼한 All-In Podcast 진행자들이 공식 복장으로 출연하고 원유·전쟁·인플레이션 같은 거시 주제를 다루는 공개 회차가, 이미 시장에 존재하는 긴장 레짐을 설명하는 문화적 마커인가?

```text
공개된 에피소드·썸네일의 Tie Day
+ 공개 제목/설명의 energy·war·Iran·OPEC·inflation 문맥
→ 미디어의 공식성 / 거시 긴장 서사
→ 이후가 아니라 동시적 시장 레짐 설명용
```

이 카드가 주장하지 않는 것: 진행자가 비공개 정보를 가졌다는 주장, 복장으로 심리·건강·정치성향을 추론하는 일, 사람을 추적하는 일, 또는 넥타이만으로 거래 신호를 만드는 일.

## 가능한 최소 기록

| 필드 | 정의 |
| --- | --- |
| `published_at` | 공식 공개 에피소드의 게시 시각 |
| `tie_count` | 공식 썸네일/영상 첫 장면에서 수동·블라인드로 확인한 넥타이 착용 진행자 수. 확인 불가면 결측 |
| `macro_context` | 제목·설명에 energy, oil, Iran, war, OPEC, inflation 등 사전 고정 공개 단어가 있는지 |
| `formal_media_marker` | `tie_count > 0`과 `macro_context = 1`의 동시 여부 |

라벨은 WTI 결과를 보지 않고 먼저 붙여야 한다. 썸네일은 재사용·교체될 수 있으므로 원본 URL, 수집 시각, 화면 캡처 해시와 함께 보관해야 한다.

## 왜 알파 검정이 어려운가

- All-In Podcast는 2020년대에 시작해 2015–2023 장기 인샘플을 채우지 못한다.
- 주간 방송은 알려진 사건을 사후 논평할 가능성이 크다.
- Tie Day 사건 수가 작고, 편집·행사·스폰서·촬영 일정이 복장에 영향을 준다.
- 공개 영상·자막은 이용약관과 재배포 조건을 확인해야 한다.

따라서 이 카드는 WTI 가격/변동성 가중치가 아니라 **대시보드의 문화적 주석**으로만 남긴다. 통계를 낸다면 동시·사후 설명과 선행 예측을 엄격히 분리한다.

## 데이터·안전 경계

- 공식 공개 에피소드의 제목·설명·게시시각·썸네일만 사용한다.
- 얼굴인식, 개인 계정·사적 사진, 위치·일정·사생활 데이터, 또는 비공개 정보 추정은 금지한다.
- 공식 채널과 데이터 이용 조건을 확인하기 전에는 자동 수집하지 않는다.
