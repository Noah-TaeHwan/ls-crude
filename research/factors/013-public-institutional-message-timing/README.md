# 013 — Public Institutional Message Timing Gate

**상태**: ⛔ **SKIP as alpha / 원안 보존**
**역할**: 이전 015 Public Khutbah Tone 카드와 016 Khutbah Signal 구현 패키지를 하나로 묶은 공개 담화 관측 아이디어.
**Oil Pizza 가중치**: `0.0`
**변동성 기준 (2026-09-03)**: 미래 5거래일 WTI 실현변동성. 사전 라벨된 적법한 장기 공개 메시지 시계열이 없어 미검증.

## 원안

공개 금요 설교문·공식 종교기관 담화에서 긴장 관련 언어의 변화가 이후 WTI 변동성 위험을 알릴 수 있다는 가설이다. 이 카드는 종교·민족·국적 집단이나 개인의 위험도를 판단하지 않는다. 공개된 **기관성 메시지의 시점과 내용 변화**만 연구 대상으로 삼는다.

## 왜 독립 알파로 종료하는가

```text
지정학 사건
  ├─ 공식 발표·통신사 보도·시장 가격 반응
  └─ 공개 설교·공개 담화의 동행 또는 후행 변화
```

가장 자연스러운 인과는 실제 지정학 사건이 시장과 담화를 함께 움직이는 것이다. 설교는 물리 공급을 바꾸는 독립 원인이 아니며, 주간 주기와 게시 시각 불명확성 때문에 빠른 뉴스보다 선행하기 어렵다.

이전 구현 패키지는 합성 설교문과, 고점수 구간에 맞춰 변동성을 주입한 합성 유가 시계열을 사용했다. 그 상관·적중률은 실증 결과가 아니다. 또한 키워드만으로는 경건·인용·정치적 맥락을 구분하기 어렵고, 번역·코퍼스 누락이 점수에 섞인다.

따라서 현재 **0.1% 이상의 독립적·재현 가능한 WTI 관계는 없다.**

## 보존되는 좁은 연구 규칙

향후 이 원안을 재검토하려면 아래를 모두 충족해야 한다.

- 공식 기관의 공개 URL, 원문 언어, 실제 게시 시각이 있는 텍스트만 사용한다.
- 공급 경로가 명시된 공개 문장(해상 항로·수출·생산·시설 운영·제재 집행)만 별도 사건으로 라벨한다.
- 동일 시점의 공식 발표·일반 지정학 뉴스·직전 WTI 변동성을 통제한 뒤에만 증분 설명력을 평가한다.
- 개인·설교자·신자 추적, 비공개 녹음, 무허가 플랫폼 스크래핑은 사용하지 않는다.

이 조건이 갖춰져도 이는 **변동성 이벤트 연구**일 뿐, 방향성 유가 매매 신호로 취급하지 않는다.
