# 043 — Overtime Latte Index (OLI)

**상태**: ⏸️ **HOLD — 밈과 메커니즘은 보존, 무료 데이터로는 소비 비율을 측정하지 못함**  
**원안**: Premium coffee consumption ÷ energy-drink consumption  
**Oil Pizza 가중치**: `0.0`

## 가설

```text
프리미엄 커피 상대 강세 → 화이트칼라 출근·도심 서비스 소비의 평시/위험선호 맥락
에너지음료 상대 강세 → 교대근무·운전·물류·생산의 피로/운영 압력 맥락
상대 변화 → 이후 단기 WTI 변동성의 아주 약한 보조 후보
```

이는 원유 가격 방향 가설이 아니다. 도시·노동 레짐의 서사를 변동성 보조 신호로 시험하는 아이디어다.

## 무료 데이터 적합성 판정

| 후보 | 얻을 수 있는 것 | 치명적 한계 |
| --- | --- | --- |
| 한국 관세청 HS 무역통계 | 커피(예: HS 0901) 수출입 월간 집계 | 국경 간 무역은 국내 소비가 아니며, 에너지음료는 단일 HS 코드가 아니다. |
| UN Comtrade | 국가별 월간/연간 HS 무역 | 구독 키·제공국·개정 문제가 있고, 역시 소비가 아니다. |
| KOSIS 커피전문점 통계 | 커피점 산업의 연/월 공개 집계 일부 | 프리미엄 여부·판매량·에너지음료와의 비교가 불가하다. |
| 체인사 실적 | 기업 매출·매장·분기 공시 | 기업별·분기별이고 전 시장 소비 비율이 아니다. |
| Google Trends | 검색 관심 | 판매/소비가 아니며 계절성·캠페인·플랫폼 변화가 더 클 수 있다. |

**결정적 문제**: ‘에너지드링크 소비량’은 공용 상품분류로 깨끗이 분리되지 않는다. 커피의 수입/수출 금액을 분자로, 혼합 음료 HS를 분모로 놓는 것은 OLI가 아니라 무역·분류 노이즈를 검증하는 일이다.

## 결론

현재 무료·공개 장기 자료로는 **0.01% 관계조차 검증하지 못했다.** 관계가 없다고 증명한 것은 아니지만, 신호를 실제로 측정하지 못하므로 숫자를 만들지 않는다.

재개는 국가/도시 단위 익명 월간 판매량 패널이 두 음료군을 분리하고, 2015년부터의 역사·라이선스·실제 공개일을 제공할 때만 한다. 그 뒤 2015–2023에서 사양을 동결하고 다음 21거래일 `CL=F` 실현변동성으로 OOS를 한 번만 실행한다.

이 원안과 출처 감사는 [OLI 조사 노트](../../gathering/notes/2026-09-03-overtime-latte-index-hold.md)에 보존한다.
