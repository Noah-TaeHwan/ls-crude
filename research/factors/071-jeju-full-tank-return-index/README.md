# 071 — 제주 렌터카 만땅 반납 지수

**상태**: ⛔ **REJECTED — 대여업체 보유대수는 실제 대여·주유·반납이 아니다.**  
**별칭**: *제주가 가득 차면 항공유도 찬다*  
**Oil Pizza 가중치**: `0.0`

## 가설

제주 렌터카의 만땅 반납·예약 부족·주유 수요와 제주공항 여객 급증이 동시 발생하면 국내 휘발유·항공유 수요 레짐의 현장 신호가 될 수 있다.

## 자료 수집 및 검정

공공 렌터카 표준데이터는 업체 위치·차고지 수용력·보유차종·요금·운영시간을 제공한다. 이는 공급 목록이지 대여 건수·연료 충전·반납 연료량이 아니다. 제주공항 여객은 공개 월간 자료지만, 기존 027 Incheon Transit의 공항 여객 프록시가 WTI 변동성에서 IS/OOS `-0.332/+0.530`으로 부호 반전한 것과도 구분해야 한다.

원안의 렌터카 연료 행동을 측정하지 못하므로 **새 가격·변동성 검정은 미실행**이다. 공항 여객만 다시 이름 붙여 071 결과로 보고하지 않는다. [감사](../../gathering/notes/2026-09-07-korea-pizza-five-factor-audit.md).
