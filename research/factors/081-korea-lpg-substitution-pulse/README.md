# 081 — Korea LPG Substitution Pulse

**상태**: ⏸️ **HOLD / untested**  
**Oil Pizza 가중치**: `0.0`

## 가설

LPG와 휘발유·경유의 상대가격이 크게 벌어질 때 택시·LPG 차량의 체감 운행비와 신규 선택 압력이 달라질 수 있다. 단, 가격차가 곧바로 실제 연료전환이나 원유 수요변화라는 뜻은 아니다.

```text
LPG–휘발유/경유 상대가격 변화
→ 차량 연료비 선택·체감 압력 후보
→ 국내 연료전환 설명 모니터
```

## 검정 설계와 한계

- Opinet 유종별 지역 평균가격으로 상대가격 스프레드만 먼저 만든다.
- 실제 차량 등록·연료 판매량·운행거리의 장기 공개 패널 및 실제 공개일을 별도로 확보해야 한다. 이 확인 전에는 ‘택시가 LPG로 바꾼다’는 주장을 사용하지 않는다.
- 타깃은 국내 LPG/휘발유 가격 전가와 소비 레짐이며 WTI 가격·변동성은 보조 반증이다. 현재 수치·상관은 없다.

## 무료 자료 후보

- [KNOC Opinet 유가정보 API](https://www.data.go.kr/data/15098558/openapi.do): LPG·휘발유·경유 지역 평균가 후보.
- 국가통계포털 차량등록·에너지 판매량 집계: 정의·역사·공표일을 실제 수집 전에 확인해야 하며, 현재 이 카드의 검정 입력은 아니다.

## 데이터 경계

지역·유종 단위 익명 집계만 사용한다. 택시 기사·운전자·결제·경로·개별 차량 데이터는 수집하지 않는다.
