# 042 — Asia Financial Hub Pulse (AFHP)

**상태**: ⏸️ **HOLD — 공개 월간 집계는 확인, 동질 장기 패널은 아직 미구축**  
**별칭**: *Overtime Latte Index*  
**Oil Pizza 가중치**: `0.0`

## 질문

홍콩·싱가포르·도쿄·서울(여의도 포함)의 공개 소비 활동이 동시에 예상 밖으로 변할 때, 아시아의 위험선호·출장/서비스 수요·운영 압력 레짐이 이후 WTI 변동성에 아주 약한 보조 정보를 주는가?

이 카드는 특정 식당, 건물, 개인, 카드결제, 예약 또는 위치 데이터를 수집하지 않는다. **도시/국가 단위의 익명 공식 집계만** 사용한다.

```text
4개 금융허브의 월간 소비·F&B 서프라이즈
  → 아시아 서비스·위험선호/운영 레짐의 공통 변화
  → 정제·항공·운송 수요 기대의 보조 맥락
  → 다음 21거래일 CL=F 실현변동성
```

## v2 — 하나의 점수가 아니라 두 개의 신호

단순 평균은 “네 도시가 함께 좋아지는 상황”과 “한 도시만 급변하는 상황”을 같은 값으로 만들 수 있다. AFHP는 다음 둘을 **절대 합치지 않고 별도로** 낸다.

| 출력 | 뜻 | 가설 | 해석 경계 |
| --- | --- | --- | --- |
| `AFHP-Pulse` | 네 도시의 소비 surprise 평균 | 동시적 서비스·출장·소비 회복은 평시 risk-on 레짐의 보조 맥락일 수 있음 | 원유 수요가 늘었다거나 유가가 오른다는 신호는 아님 |
| `AFHP-Divergence` | 네 도시 surprise의 횡단면 표준편차 | 금융/관광/환율 충격이 지역별로 엇갈릴수록 불확실성이 커져 변동성 맥락이 될 수 있음 | 분산이 크다고 공급 차질·경기침체라고 단정하지 않음 |

예를 들어 서울·도쿄·홍콩·싱가포르가 모두 평균보다 높으면 `Pulse`가 높고 `Divergence`는 낮다. 한 도시만 급락하고 나머지가 보통이면 `Pulse`는 평범해도 `Divergence`가 높다. 이 분리는 이 팩터의 핵심이다.

## 고정할 테스트 사양

| 항목 | 정의 |
| --- | --- |
| 대상 도시권 | Hong Kong, Singapore, Tokyo, Seoul. 여의도는 서울 전체의 공식 집계로 대체하지 않으며 별도 신호로 주장하지 않는다. |
| 입력 | 각 기관이 공개한 계절조정 실질 소매 또는 F&B 지수의 전월 변화. 가격효과를 줄이기 위해 volume index를 우선한다. 홍콩·싱가포르는 도시권 전체, 도쿄는 23구/동일 정의의 고정 통계, 서울은 서울 전체 공개 지수로 한정한다. |
| surprise | 계절조정 전월 변화에서 해당 도시의 직전 36개월 평균을 뺀 뒤 표준편차로 나눈다. 36개월 미만 초기 구간은 신호를 만들지 않는다. |
| 합성 | `Pulse = 4개 도시 surprise 평균`, `Divergence = 4개 도시 surprise의 횡단면 표준편차`. 도시 하나라도 빠진 달은 둘 다 계산하지 않는다. |
| 공개시점 | 관측월 말이 아닌 각 기관의 실제 발표 시각 후 첫 `CL=F` 거래일. 과거 현행치만으로는 테스트하지 않고 release calendar/vintage를 보존한다. |
| 타깃 | 그 뒤 다음 21거래일 `CL=F` 실현변동성. |
| 통제 | 직전 21일 WTI 실현변동성, 달러, 아시아 주식 risk-on, 중국 경기/휴일 계절성을 사전 고정한다. `Pulse`와 `Divergence`의 증분 설명력만 본다. |
| 통과 | IS에서 두 출력 중 하나의 방향·사양을 동결하고, OOS에서 같은 방향·`|r| ≥ 0.10` 또는 기준모형 대비 사전 정의한 증분이 재현될 때만 후보로 남긴다. |
| 선정 | 2015–2023에서만 사양을 동결한 뒤, 2024년 이후은 한 번만 OOS로 연다. |

## 데이터 수집 단계와 실패 규칙

1. 각 기관의 **원본 CSV/XLSX와 해당 release calendar**를 `gathering/raw/`에 같이 보관한다.
2. 도시, 관측월, 발표일시, vintage, 계절조정 여부, 값, 원본 파일 해시를 한 행으로 정리한다.
3. 네 도시가 모두 충족되는 공통 월부터만 패널을 연다. 빈칸을 보간하거나 한 도시를 대체하지 않는다.
4. 2015–2023에서 도시 정의·입력 계열·통제·타깃을 잠근 뒤에만 OOS를 연다.

다음이면 폐기한다: (a) 당시 공개일을 재현하지 못함, (b) 결과가 한 도시만으로 설명됨, (c) 통제 뒤 소멸, (d) OOS에서 부호 반전.

## 042A — 단일 도시 버전: Wall Street District Pulse

여의도·월스트리트·도쿄·싱가포르 CBD를 무료 공개자료의 역사·빈도·자동수집성으로 비교한 결과, **Lower Manhattan**이 첫 단일 도시 후보가 됐다. 뉴욕주 공식 MTA turnstile 아카이브는 `WALL ST`, `BROAD ST`, `FULTON ST`, `RECTOR ST`, `CORTLANDT ST` 같은 역의 익명 출입량을 장기 제공한다.

```text
Lower Manhattan 역군의 평일 출입량
− 요일·월·휴일 기대값
= Wall Street District Pulse 이상치
→ 실제 공개 뒤 WTI 변동성의 약한 보조 맥락인가?
```

이는 월스트리트 종사자·주문·건물·식당을 추적하지 않으며, 금융활동 또는 석유 수요를 직접 추론하지 않는다. 2015–2022 turnstile 계열로 사양만 고정하고, 2020 이후 다른 MTA hourly-ridership 방법론을 억지로 연결해 OOS라고 부르지 않는다. 상세 비교와 데이터 계약은 [단일 금융지구 탐색 노트](../../gathering/notes/2026-09-03-district-pulse-location-scan.md)에 있다.

## 왜 가격 방향 팩터가 아닌가

네 도시의 소비 규모가 글로벌 원유 물리 수요를 독자적으로 움직인다고 주장할 근거는 없다. 공개 월간 소비는 늦고, 이미 알려진 경기·관광·환율 요인을 반영할 가능성이 크다. 따라서 설령 남는 관계가 있더라도 **WTI 방향 매매가 아니라 변동성 레짐의 미약한 보조 후보**다.

## 현재 판정

**0.01% 탐색 가치는 있다. 0.1% 독립 알파는 아직 전혀 확인되지 않았다.** 네 입력의 빈도·정의·실제 발표일을 맞춘 원시 패널이 없으므로 지금 수치를 만들면 look-ahead와 이질 지표 혼합이 된다. 그 전에 상관계수나 매트릭스 수치를 쓰지 않는다.

2026-09-03 접근성 점검에서 홍콩의 공개 데이터셋, 일본 e-Stat 표, KOSIS 통계 포털은 확인했다. SingStat TableBuilder 자동 API는 이 환경에서 정상 JSON 응답 대신 서비스 오류 페이지를 반환했고, KOSIS는 인증 없는 호출로는 데이터 계약을 확정하지 못했다. 이 둘의 적법한 다운로드·공개일 패널을 확보하기 전에는 테스트하지 않는다.
