# 031 — Live Commerce Burn Rate (LCBR)

**상태**: 🗃️ **IDEA ARCHIVED / sub-hypothesis of 027**  
**Oil Pizza 가중치**: `0.0`

## 원안

한국발 중국 대상 라이브커머스 흥행이 야간 출고·트럭·항공화물을 늘려 디젤·항공유 수요와 WTI 변동성을 앞설 수 있다는 가설이다.

## 판정

공개 스트림 수·시청자 수는 주문·판매액·출고국·운송수단·연료소비가 아니다. 플랫폼·제3자 판매 대시보드, 개별 주문과 물류 이벤트를 수집해 이를 추정하는 것은 데이터 적격성과 개인정보 경계 밖이다. 제시된 방송별 판매·추가 화물편·WTI 사례도 검증 가능한 출처가 없어 채택하지 않는다.

검증 가능한 공개 집계는 인천공항의 월간 여객·화물 등이며 이는 이미 `027 Incheon Transit Surge`의 범위다. 따라서 LCBR은 별도 거래 팩터가 아니라 **Clicks → Combustion**이라는 설명용 하위 아이디어로만 보존한다.

이는 2026-09-03 입력의 `#10 Live Commerce Burn Rate` 원안을 병합한 기록이다.

## 변동성 테스트

적격한 장기 신호가 없으므로 IS/OOS 상관을 계산하지 않았다.
