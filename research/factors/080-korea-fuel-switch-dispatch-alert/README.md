# 080 — Korea Fuel-Switch Dispatch Alert

**상태**: ⏸️ **HOLD / untested**  
**Oil Pizza 가중치**: `0.0`

## 가설

전력계통에서 유류 발전 비중이 평시 대비 급증하거나 급감하면, LNG·석탄·재생에너지 제약과 국내 전력연료 수요의 스트레스를 드러낼 수 있다.

```text
연료별 발전량/거래량의 예상 밖 변화
→ 전력 연료믹스 전환
→ 국내 유류·LNG·전력 스트레스 맥락
```

국내 유류 발전은 글로벌 원유시장을 혼자 움직일 규모가 아니다. 이 카드는 WTI 방향 신호가 아니라 **연료전환 경보** 후보이다.

## 검정 설계와 한계

- KPX 연료별 발전량·거래량에서 ‘유류’ 분류와 실제 시간/일/월 공개 방식을 먼저 고정한다.
- 1차 타깃은 전력연료·LNG 관련 변동성 또는 국내 전력 스트레스이며, WTI/Brent는 보조 반증이다.
- 공개 카탈로그에서 일·시간 연료별 자료 후보와 일부 연도 아카이브는 확인했지만, 연속 역사·개정·공표시점을 아직 감사하지 않았다. 결과값은 없다.

공개 계통 집계만 사용한다. 특정 발전소·운영자·근로자 행동, 비공개 고장·수급 정보를 추론하거나 수집하지 않는다.
