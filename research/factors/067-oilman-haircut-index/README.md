기존 033·034의 같은 문제를 독립 번호로 반복하지 않으며, **가격·변동성 IS/OOS 검정은 미실행**이다. 개인의 외모나 사생활을 데이터화하지 않는다는 결정을 포함해 [감사 노트](../../gathering/notes/2026-09-07-pizza-style-five-factor-audit.md)에 보존한다.
