# 030 — Instant Noodle Panic Index (INPI)

**상태**: ⏸️ **HOLD / meme monitor, test required**  
**Oil Pizza 가중치**: `0.0`

## 원안의 보정

면세점 라면 판매 → 수하물 → SUV·배송 → WTI라는 사슬은 공개 데이터로 검증할 수 없고, 규모상 글로벌 원유 변동성의 직접 원인으로 가정할 수 없다.

남기는 검증 가능한 질문은 더 좁다.

```text
사전 고정한 HS 코드·대상국 기준의 한국 인스턴트면 수출 월간 surprise
→ 다음 21거래일 CL=F 실현변동성
```

이는 원유 수요 신호가 아니라 K-소비재 수출·글로벌 소매재고·환율의 혼합 맥락이다. 상관이 발견되더라도 물류 연료수요 인과로 해석하지 않는다.

## 데이터와 경계

관세청은 국가·HS 코드별 월간 무역통계를 제공하고, 잠정치는 월중 11일·21일 및 익월 1일, 확정치는 통상 익월 15일에 공표한다고 설명한다. 실제 HS 분류, 장기 역사, 수정 빈티지와 API/재배포 조건을 수집 전에 확정해야 한다.

- 기업·면세점의 주간 품목 판매, 주문, 수하물, 차량·배송 데이터를 쓰지 않는다.
- 수출 통관 시점이 아닌 실제 공표시점 뒤에만 신호를 쓴다.
- 2015–2023 IS에서 사양을 고정하기 전 OOS를 열지 않는다.

## 변동성 테스트

아직 HS 코드·국가 바스켓과 공개시점이 동결되지 않아 IS/OOS 수치를 계산하지 않았다.
