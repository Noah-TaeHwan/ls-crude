**상태**: ⏸️ **HOLD / public institutional context**

## 가설

공식적으로 공개된 군 모집·인력 통계의 변화가 노동시장·국방 예산·기관 운영 맥락과 WTI 변동성의 관계를 탐색할 수 있다는 가설이다.

## 범위

공식 공고·집계만 사용한다. 모집 공고나 예산을 임박한 파병·작전 신호로 해석하지 않으며, 개인 지원자·지역별 모집·부대별 충원 데이터를 수집하지 않는다.

## 현재 결과

모집 집계는 저빈도이며 경로도 국방 예산·노동시장과 강하게 섞인다. 아직 실제 공개시점이 있는 장기 일관 시계열을 확보하지 못했으므로 IS/OOS 상관은 `—`다.
