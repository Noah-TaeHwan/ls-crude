# 032 — Korea Weather & Transport Disruption Context

**상태**: ⏸️ **HOLD / domestic context only**  
**Oil Pizza 가중치**: `0.0`

## 병합 원안

이 카드는 사용자 제안 `#12 Yellow Dust Surge`, `#19 Jeju Green Hydrogen Flip`, `#20 Jeju Wind-Surge Flip`을 한 곳에 보존한다. 황사·강풍·재생에너지 출력 저하가 국내 이동·항공·선박·백업발전 부담을 높일 수 있다는 국내 운영 맥락이다.

## 판정

황사 경보와 기상 관측은 공개 경로가 있지만, 이들이 한국의 단기 연료 소비를 통해 글로벌 WTI 변동성을 6–36시간 선행한다는 물리적 근거는 없다. 기상은 상당 부분 사전 예보되고, 실제 항공·선박 차질은 공개 확인 후에야 안다. 수소 출력 저하를 디젤 전환으로 단정할 공개 장기 시계열도 없다.

따라서 이것은 **국내 운영·여행 대시보드 맥락**이며, WTI 거래 알림이나 가중치가 아니다. 제안 원문 속 2025년 연료·WTI 반응 사례는 검증된 출처가 없어 사실·성과 사례로 채택하지 않는다.

## 향후 반증 규칙

사전 등록한 황사 경보 또는 제주 풍속 이상이 실제 공표된 뒤에만, 다음 5거래일 `CL=F` 실현변동성과의 관계를 2015–2023 IS에서 단 한 사양으로 시험한다. 공개 운항 차질·발전 출력 자료의 역사, 발표 시점, 개정 이력이 확보되기 전에는 수치를 계산하지 않는다.
