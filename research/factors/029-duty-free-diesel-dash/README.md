# 029 — Duty-Free Diesel Dash (DFDD)

**상태**: 🗃️ **IDEA ARCHIVED / sub-hypothesis of 027**  
**Oil Pizza 가중치**: `0.0`

## 원안

외국인 면세점 매출·이용객 급증이 관광객의 렌터카·셔틀·재고보충 물류를 통해 한국 디젤 수요와 WTI 변동성을 높인다는 가설이다.

## 판정

공개 관세청 면세점 통계는 내·외국인 매출과 이용객의 월간 집계이지 중국 관광객, 개별 품목, 출고지, 렌터카·셔틀 운행량 또는 연료소비를 식별하지 않는다. 온라인·오프라인도 분리되지 않는다. 따라서 면세 매출을 중국인 관광·디젤 소비로 귀속할 수 없고, 한국의 국지적 물류 변화가 WTI 변동성을 이끈다는 경로도 입증되지 않았다.

`027 Incheon Transit Surge`의 관광·항공 수요 **설명용 하위 가설**로만 보존한다. 개인 구매·주문·배송·차량 데이터를 수집하지 않는다.

`#14 Incheon Duty-Free Diesel Loophole`도 이 카드에 병합한다. 면세 판매가 별도 ‘디젤 판매’나 민간 차량 연료소비를 뜻한다는 공개 근거는 없다.

## 변동성 테스트

원안 신호(품목별 면세 라면·중국인 관광객 연료수요)의 공개 장기 시계열이 없어 IS/OOS 상관을 계산하지 않았다.
