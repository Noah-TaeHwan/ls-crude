# 079 — Korea Naphtha Export Thermometer

**상태**: ⏸️ **HOLD / untested**  
**Oil Pizza 가중치**: `0.0`

## 가설

한국의 나프타·석유화학 수출입에서 물량과 단가가 엇갈리면, 아시아 정유·크래커 마진과 제품 수요의 변화를 보여 줄 수 있다.

```text
나프타·석유화학 무역 물량/단가 괴리
→ 아시아 feedstock·제품 수요의 압력 후보
→ 한국 석유화학·정제품 맥락, 이후에만 WTI/Brent 반증
```

이는 월간·지연된 무역자료다. 단기 WTI 선행 알파라고 부르지 않으며, **한국·아시아 제품 수요 온도계**로 먼저 검증한다.

## 사전 고정 수집 원칙

- 나프타와 석유화학 제품 HS 코드는 관세청 분류 설명과 함께 사전 고정한다. 비슷해 보이는 HS 코드를 사후 선택하지 않는다.
- 금액만이 아니라 수량·단가를 분리하고, 수량은 계절조정 또는 전년동월 비교 뒤에 사용한다.
- 관측월이 아니라 실제 무역통계 공개일 뒤에만 신호를 쓴다.

## 검정 설계와 한계

- 1차 타깃: 한국 석유화학·정유 체인 또는 정제품 마진의 다음 달 변동성/수익률. 이용 가능한 공개 타깃이 없으면 WTI 검정부터 하지 않는다.
- HS 바스켓, 역사 연속성, 당시 공개일·개정 빈티지를 아직 고정하지 않았다. 현재 결과값은 없다.

## 무료 자료 후보

- [관세청 수출입무역통계](https://tradedata.go.kr/cts/index_eng.do): 품목·국가별 월간 공개 통계 후보.
- [UN Comtrade API 문서](https://uncomtrade.org/docs/un-comtrade-api/): 한국 자료 교차검증 후보. API 범위·키·재사용 조건은 실행 전 확인한다.

## 데이터 경계

국가·품목 단위 집계만 쓴다. 특정 수출사·계약·선적·고객·운송사를 식별하거나 추정하지 않는다.
