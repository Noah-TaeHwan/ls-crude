# 082 — Korea Kitchen Oil Stress / Palm–WTI Cointegration

**상태**: ⏸️ **HOLD / untested**  
**Oil Pizza 가중치**: `0.0`

## 한 줄 결론

“김치 크루드”는 좋은 밈이지만, 식용유 가격이 WTI를 먼저 안다는 주장은 아직 없다. 이 카드는 먼저 **식물성 유지류·환율 → 한국 식용유 가격**의 전가를 검정하고, 별도로 팜유–WTI의 공적분·잔차 평균회귀가 거래 가능한지 반증한다.

```text
대두유·팜유·카놀라유 + USD/KRW
      → 한국 식용유 원가·소매 전가
      → 가계 식품물가 스트레스

팜유 ↔ WTI
      → 공통 거시·달러·인플레이션 관계일 수 있음
      → 공적분 자체는 WTI 선행 알파가 아님
```

## 입력과 타깃의 우선순위

| 구분 | 사전 후보 |
| --- | --- |
| 원료 | 팜유·대두유·카놀라유 국제 가격 |
| 국내 전가 | KAMIS의 식용유 소매가격이 실제 장기 연속 시계열로 제공되는지 먼저 확인 |
| 통제 | USD/KRW, 원유, 계절성 |
| 1차 타깃 | 다음 달 한국 식용유 가격 또는 식품 CPI 변화 |
| 2차 타깃 | 팜유/WTI 스프레드 잔차의 평균회귀 |
| 금지된 결론 | ‘식용유 급등이 며칠 뒤 WTI 상승을 예고한다’는 서사 |

## 제공된 공적분 코드에 대한 적용 규칙

제안된 흐름(ADF → Engle–Granger → OLS hedge ratio → 잔차 ADF → rolling)은 **진단 도구**로 채택한다. 그러나 아래 조건 없이는 알파 판정을 하지 않는다.

1. 팜유와 WTI의 로그 수준 공적분 p-value만으로는 채택하지 않는다. 공통 달러·물가·성장 레짐에 따른 가성 관계일 수 있다.
2. `candidate_break_scan`에서 가장 큰 차이를 낸 분할점을 채택하지 않는다. 다중 탐색의 선택편향이다. 2020-03, 2022-02처럼 사전 지정한 사건일만 별도 분할하거나, 별도의 bootstrap sup-test를 사용한다.
3. 분할 검정에서는 경계 관측치를 pre와 post 양쪽에 중복 넣지 않는다.
4. hedge ratio·잔차 z-score·진입 임계값·보유기간을 2015–2023에서 고정한다. 이후 2024+에서 한 번만 OOS를 연다.
5. 최종 검정은 공적분 p-value가 아니라 `잔차 |z| ≥ 2`일의 다음 5·10·20일 수익률/변동성과 비용 후 성과다.

## 보류 사유

- 한국 식용유의 동일 품목·동일 용량·장기 소매 가격 시계열, 당시 공개일, 개정 이력을 아직 확보하지 않았다.
- 식물성 유지류 시장은 기상·바이오디젤·수출정책 영향을 크게 받는다. WTI보다 이들 원료가격과 환율이 직접 입력이다.
- 따라서 IS/OOS 상관, 공적분 p-value, hedge ratio, 거래 성과는 아직 **없다**.
