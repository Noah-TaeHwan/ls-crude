**밈**: *“MBA들이 휴가 가면 시장도 조용해지는가?”*

## 원안을 어떻게 살렸나

학교·자격시험별 하드코딩 일정은 불완전하고 결국 계절성을 중복 계수한다. 따라서 “특정 학생이 시장을 움직인다”는 주장은 버리고, 북반구 금융·학사 휴식기에 겹치는 두 공개 달력창만 사전 고정했다.

```text
Summer quiet:   7월 1일–8월 31일
Year-end quiet: 12월 15일–1월 5일
→ 다음 5거래일 WTI / RBOB / MPC 실현변동성
```

이는 거래자·학생의 행동을 측정한 데이터가 아니라 **계절성 리스크 필터의 반증**이다.

## 실제 검정

- IS: 2015–2023 / OOS: 2024–2026-09-03
- 가격: 이미 보관된 Yahoo `CL=F`, `RB=F`, `MPC` 일봉
- 타깃: 당일 수익률을 제외한 다음 5거래일 실현변동성
- 회귀: 연도·요일 더미, HAC(5)
- 다중검정: 각 IS/OOS에서 3자산 × 2창 = 6개 HAC p값 BH 보정
- 통과 조건: WTI에서 동일 방향, IS·OOS 모두 BH `q<.05`

| 자산·창 | IS HAC p / q | OOS HAC p / q | 판정 |
| --- | --- | --- | --- |
| WTI 여름 | `.0757 / .1775` | `.5802 / .8147` | OOS 소멸 |
| WTI 연말 | `.1479 / .1775` | `.0549 / .1647` | 양쪽 미통과 |
| RBOB 여름 | `.4391 / .4391` | `.8517 / .8517` | 없음 |
| RBOB 연말 | `.1222 / .1775` | `.0077 / .0462` | OOS 단독 발견값; IS 미재현 |
| MPC 여름 | `.0604 / .1775` | `.4719 / .8147` | OOS 소멸 |
| MPC 연말 | `.1424 / .1775` | `.6789 / .8147` | 없음 |

WTI 여름은 IS에서 RV5가 비창보다 `-1.675%p` 낮았지만 OOS 차이는 `+0.138%p`로 뒤집혔다. WTI 연말도 IS/OOS 사건 차이는 각각 `-1.509%p/-1.557%p`이지만, 보정 검정에서 통과하지 못했다.

## 결론

학사 휴식기라는 서사는 흥미롭지만, 관측된 것은 일반적인 여름·연말 계절성일 뿐이고 WTI 선행 알파는 아니다. RBOB 연말 OOS 하나를 보고 규칙을 만들지 않는다. 대시보드에서 “calendar context”로 표시할 수는 있으나 거래 가중치는 `0.0`이다.
