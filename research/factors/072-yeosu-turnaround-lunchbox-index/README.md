# 072 — 여수 보수철 도시락 지수

**상태**: ⛔ **REJECTED — 도시락·숙박 수요 공개 시계열이 없다.**  
**별칭**: *도시락이 쌓이면 설비가 멈춘다*  
**Oil Pizza 가중치**: `0.0`

## 가설

여수 산단의 도시락·숙소·임시 인력 수요 증가는 석유화학/정유 설비 정기보수의 생활 흔적이고, 한국 정유주·아시아 제품 스프레드 변동성의 보조 신호일 수 있다.

## 자료 수집 및 1차 검정

산업단지공단의 공개 자료는 분기별 산단별 입주업체·업종 고용 같은 느린 구조 통계다. 도시락, 숙박 점유율, 정비 인력의 익명 집계가 아니다. 공개 공고·뉴스를 정비 시점의 선행 신호로 바꾸면 사후 보도·look-ahead 위험이 생긴다.

따라서 입력값이 없어 **IS/OOS 검정은 미실행**이다. 실제 재개에는 시설 또는 복수 사업자가 동의한 권역 단위 익명 월간 숙박/식사 집계와 공개시각이 필요하다. [감사](../../gathering/notes/2026-09-07-korea-pizza-five-factor-audit.md).
