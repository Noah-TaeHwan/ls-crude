# 014 — Pipeline Noise & Public Seismic Proxy Signal

**상태**: ⏸️ **HOLD** — 물리적 조기경보 가설은 흥미롭지만, 공개 관측소 자료로 파이프라인 이상을 식별할 수 있는지 미확인.
**원본 패키지**: `017-pipeline_noise_signal.zip`
**변동성 기준 (2026-09-03)**: 미래 5거래일 WTI 실현변동성. 공개 관측소가 파이프라인 상태를 식별하는 시계열이 없어 미검증.

**번호 변경 기록**: 이전 017. 원안 패키지명은 재현성을 위해 유지한다.

## 가설

주요 원유 파이프라인 회랑 주변 공개 지진·인프라사운드 관측값의 비정상적인 변화가 실제 운영 제한·누유·폐쇄와 시간적으로 연결된다면, 이후 WTI `CL=F` 변동성 위험을 관찰하는 보조 게이트가 될 수 있다.

이것은 파이프라인에서 나는 소리를 직접 측정한다는 주장이 아니다. 공개 관측소는 거리·기상·지진·산업 활동의 영향을 크게 받는 거친 외부 프록시다.

## 패키지가 하는 일

`017-pipeline_noise_signal.zip`은 관측소별 에너지 시계열을 입력으로 받아 지역 기준선 대비 이상치를 만들고, 회랑 단위 위험 플래그로 집계하는 연구용 구조를 제공한다. 포함된 데모 시계열과 유가 레짐은 합성 데이터이므로 실증 결과가 아니다.

## 데이터 적격성

| 확인 항목 | 통과 기준 |
| --- | --- |
| 관측소 | 공개 네트워크·좌표·라이선스·연속 관측 가용성이 기록됨 |
| 회랑 | 파이프라인 구간과 관측소 거리·지형을 사전 등록 |
| 사건 라벨 | 공식 운영사·규제기관의 공개 운영 제한 또는 사고 공시 |
| 교란 | 지진·날씨·공사·도시 소음·계측기 변경을 별도 더미로 처리 |
| 시간정렬 | 관측 및 공개 가능 시점 뒤에만 피처 사용 |
| 타깃 | 미래 WTI 실현변동성 우선; 수익률 방향은 별도 검정 |

## 금지선과 결론

- 운영사 SCADA, 비공개 감시망, 현장 침입 데이터는 사용하지 않는다.
- 단일 관측소 스파이크를 사고·파괴행위·공급 차질로 해석하지 않는다.
- 최소 두 독립 관측소와 공개 사건 라벨이 없는 구간은 **FAIL/HOLD**다.

현재 가중치는 `0.0`이다. 공개 자료가 실제 파이프라인 상태를 식별한다는 증거가 생기기 전에는 Oil Pizza에 넣지 않는다.
