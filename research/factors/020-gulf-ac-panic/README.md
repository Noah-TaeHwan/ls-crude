## 원안

> “사람들이 에어컨 수리기사를 찾기 시작하면, 사막의 전력과 석유 시스템이 먼저 비명을 지른다.”

```text
비정상 고온 / 냉방 부하 압력
  → 전력 피크·연료 직소각·운영 지연 가능성
  → 걸프 지역 수급 마찰 또는 불확실성
  → 이후 WTI 변동성 레짐
```

이 연결은 기온만으로 성립하지 않는다. 전력부하·정전·수리 주문·석유 직소각은 서로 다른 관측값이며, 하나를 다른 하나로 단정하지 않는다.
