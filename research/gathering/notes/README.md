# notes — 한 장 정리

AI나 사람이 조사한 것을 **링크 가능한 한 장**으로 둡니다. 원문 덤프가 아닙니다.

1. [`_TEMPLATE.md`](_TEMPLATE.md)를 복사합니다.
2. 이름을 `YYYY-MM-DD-짧은-슬러그.md`로 저장합니다.
3. 새 출처는 [`../sources/REGISTRY.md`](../sources/REGISTRY.md)에도 한 줄.
4. 실제 후보는 [신규 원장](../../candidates/ledger.csv)과 [상세 카드](../../candidates/_TEMPLATE.md)에 기록합니다.
5. 승격되면 [`../../../docs/experiments/`](../../../docs/experiments/README.md)에 `NNN` 카드.

성과 숫자를 지어 내지 않습니다. 인샘플 밖에서 고르지 않습니다.

시점·누수·미실행·판정은 [검정 규약](../../../docs/testing-protocol.md)과 [기록 규약](../../../docs/recording-standard.md)을 따릅니다.
