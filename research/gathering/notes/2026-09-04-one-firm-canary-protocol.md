# One Firm Canary — 007B 파일럿 프로토콜

| 칸 | 값 |
| --- | --- |
| 날짜 | 2026-09-04 |
| 상태 | 파일럿 설계 / 데이터 미수집 |
| 관련 팩터 | 007B One Firm Canary |
| 목표 | 한 고급 이민로펌의 익명 안전이민 수요를 국소 위험인식 관측소로 시험 |

## 가설

한 안전국 이민로펌의 주간 신규 문의·유료 계약이 평소보다 급증하면, 그 로펌 고객군의 위험인식이 변화했을 수 있다. 이는 유가 상승 예측이 아니라 금·FX·원유 및 정제품 변동성의 **보조 모니터링** 가설이다.

## 최소 입력 계약

제휴사는 스스로 집계한 주간 열만 제공한다.

| 허용 열 | 처리 |
| --- | --- |
| 제공 주 종료일·실제 제공시각 | 공개 가능 시점 정렬에 사용 |
| 신규 문의 건수·유료 계약 건수 | 전체 합계만 |
| 넓은 출신권역·안전국 목적지 비중 | 각 셀 10건 이상일 때만 |
| 광고·수임료·인력·정책 변화 플래그 | 교란 통제 |

이름, 연락처, 정확 국적, 출생일, 자산, 비자 사건번호, 상담 내용, 계약금, 결제·계좌·에스크로 내역, 개별 신청 결과는 받지 않는다. 원시 집계는 GitHub·공개 대시보드에 올리지 않는다.

## 고정 검정

- `canary_z`: 52주 기준 신규 문의 및 유료계약 변화의 사전 고정 z-score.
- 타깃: 제공시각 뒤 5·20거래일 금·해당국 FX·원유 및 RBOB 실현변동성.
- 최소 104주. 이보다 짧으면 사건 사례집·모니터링으로만 기록한다.
- 2015–2023 역사가 있으면 IS에서 사양을 고정하고, 2024+ OOS는 한 번만 평가한다.

## 해석 경계

한 로펌의 급증은 광고, 추천 네트워크, 수임료, 직원 이동, 지역 행사, 비자정책으로도 발생한다. 따라서 유의한 수치가 나와도 독립 기관 재현 전에는 “글로벌 엘리트 이탈”이나 매매 알파로 주장하지 않는다.

## 공개 수집 접근성 확인 — 2026-09-04

한 뉴질랜드 고급 이민로펌의 역사적 신규 문의·유료 계약·투자이민 전환 집계를 공개 웹에서 찾으려 했으나, 공개된 것은 로펌의 서비스·정책 해설과 정부 전체 통계뿐이었다. 공개 웹 트래픽, 검색 관심도, 게시글 수, 리뷰 수를 고객 수요로 바꾸지 않았다.

| 후보 | 실제로 확인된 것 | 007B 입력 적격성 |
| --- | --- | --- |
| 개별 로펌 공개 페이지 | 투자이민 서비스·정책 해설 | 부적격 — 문의·계약·전환 집계 없음 |
| Immigration NZ AIP 통계 | 2025-04 이후 전체 신청·승인·투자 파이프라인, 분기 업데이트 | 부적격 — 한 로펌 데이터가 아니며 IS 역사 없음 |
| Immigration Advisers Authority 연간 통계 | 면허 보유자·민원 등 산업 규제 통계 | 부적격 — 고객수요·안전이민 의도 측정 아님 |

**판정**: 공개 소스만으로 007B 데이터 수집·백테스트는 실행하지 않는다. 실제 파일럿은 로펌이 위 최소 입력 계약에 맞춰 자발적으로 제공한 익명 주간 집계가 있을 때만 시작한다.
