# DoD Budget Announcement → LMT Options Scheduler 감사

| 상태 | 보류 — 코드 감사만, 라이브 스케줄·데이터 수집·거래 미실행 |

## 목적

DoD 예산 요청 발표일을 공식 공개 자료로 포착하고, LMT 옵션 체인을 발표 전후 거래일에 수집하는 **관측 인프라** 후보다. 이는 원유 팩터·UAP 팩터·Filing Delta Drift 검정 결과가 아니며, 옵션 매도 전략의 알파를 증명하지 않는다.

## 코드 감사 결과

| 항목 | 판정 | 이유 |
| --- | --- | --- |
| 서비스 루프 | 실패 | `datetime.time.sleep(2)`는 존재하지 않는다. 표준 `time.sleep(2)`가 필요 |
| 시간대 | 부적격 | naive datetime에 “16:05 EST”를 붙였다. 미국 동부 DST·휴장·조기폐장을 반영하지 못함 |
| 이벤트 창 | 부적격 | `±1/±2` 달력일만 더해 주말을 거른다. NYSE 거래일 캘린더 기준 T−1/T/T+1/T+2가 필요 |
| RSS 날짜 포착 | 불완전 | 최근 20개 항목·ISO `YYYY-MM-DD`만 찾는다. 본문 속 과거 날짜·비관련 날짜를 이벤트일로 오인할 수 있고 일반 월 이름 날짜는 놓침 |
| 이벤트 확인 | 불충분 | RSS 검색은 후보 탐지일 뿐이다. 발표일/시각은 공식 예산 문서·보도자료로 사람 또는 별도 검증 단계가 확인해야 함 |
| 예시 날짜 | 제거 필요 | `2027-03-09`는 예시라고 명시돼도 자동 등록하면 실제 공시일처럼 작동할 수 있음 |
| 영속성 | 부적격 | 메모리 set만 써 재시작 시 중복 잡을 막지 못함 |
| 옵션 데이터 | 미구축 | `run_lmt_ingestion_pipeline`의 구현·라이선스·bid/ask·IV·저장 정책이 제공되지 않음 |

## 실행 경계

- 이 감사에서는 RSS 호출, 스케줄러 실행, 옵션 체인 수집, 주문 또는 거래를 하지 않았다.
- 역사 옵션 bid/ask 없이 만든 IV crush·PnL·Sharpe는 실증 백테스트로 기록하지 않는다.
- 실제 서비스라면 공식 공개일을 확인한 **수동 승인된 이벤트 레코드**만 영속 저장하고, ET timezone-aware NYSE 달력으로 수집 시점을 계산해야 한다.

## 다음 한 가지

실제 공개 이벤트 레코드와 적법한 옵션 체인 데이터 출처가 준비될 때만, 별도 비거래 관측 파이프라인으로 재검토한다.
