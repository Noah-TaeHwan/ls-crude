# 057 HIMI Public Proxy v7 — 제공 엔진 감사

| 항목 | 값 |
| --- | --- |
| 날짜 | 2026-09-04 |
| 대상 | 사용자 제공 `HIMI057PublicProxyEngine` 코드 |
| 결론 | 새 검정 결과로는 미채택. 공개시점·표본 단위 수정 뒤에만 재실행 가능 |

## 통과한 부분

- 입력을 EIA 정유 가동률·FRED `IPG333S`·WTI로 제한해 출처가 명확하다.
- rolling z-score가 `series.shift(1)`을 사용하므로, **같은 일** 현재값을 평균·표준편차 창에 넣는 직접 누출은 피한다.
- `t+1 ... t+21` 수익률로 전방 변동성을 계산하려는 의도는 올바르다.

## 수정이 필요한 부분

1. **FRED lag 기준일**: `IPG333S` 월간 관측 날짜는 월초다. `apply_publication_lag`가 날짜에 45일만 더하면 월초+45일이 되어 관측월 전체를 알고 있는 셈이다. 이 연구의 보수 규칙은 `관측월 말 +45일`이다.
2. **일별 forward-fill 중복**: `construct_proxy_factor`는 저빈도 값을 일별로 전개한 뒤 일별 252개 창 z-score와 일별 겹침 RV21 상관을 계산한다. 동일 공개값이 여러 날 반복되어 독립 표본이 아니며, 월간 입력의 실제 표본 수를 수백·수천으로 부풀린다. 공개 이벤트별 한 행으로 평가해야 한다.
3. **IS/OOS 경계**: 기본 `2023-01-01`은 기존 연구의 동결 경계가 아니다. 사전 고정된 분할은 `2015-01-01~2023-12-31` IS, `2024-01-01~` OOS다.
4. **입력 계약**: 기본 가격 열은 `close`지만 표준 연구 파일은 `Close`다. CLI에서 `--wti-price-col Close`를 강제하거나 로더가 대소문자를 명시적으로 검증해야 한다.
5. **빈티지 한계**: 고정 lag는 실제 최초 공표시각을 완전히 복원하지 못한다. FRED·EIA의 현행 개정값만으로는 strict point-in-time 백테스트가 아니다.

## 승인 가능한 재실행 규칙

1. FRED 효과일은 `(관측월 말) + 45일`로 계산한다.
2. EIA 효과일은 보고 주 종료 +5일이다.
3. 각 효과일에 새로 공개된 합성 관측치 하나만 생성하고, 그 일보다 엄격히 뒤의 21개 `CL=F` 거래일 RV와 결합한다.
4. 동일가중·36개 직전 관측치 z-score·IS/OOS 경계 2024-01-01을 사전에 고정한다.
5. 새 수치는 기존 057 기록과 비교하되, 변동성 정의·표본 단위를 바꾸면 별도 사양으로 표기한다.

현재 채택된 결과는 [057 공개 프록시 검정 기록](2026-09-04-himi-public-proxy-test.md)을 따른다: 합성 IS `-0.177` (n=107), OOS `+0.465` (n=31), 부호 반전으로 HOLD다.
