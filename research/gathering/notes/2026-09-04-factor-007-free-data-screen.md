# 007 무료 공개 데이터 스크린 — 이란 → 뉴질랜드 거주비자

| 칸 | 값 |
| --- | --- |
| 날짜 | 2026-09-04 |
| 상태 | HOLD 유지 / 설명적 스크린 완료 |
| 관련 팩터 | 007 MENA Elite Mobility & Safe-Haven |
| 데이터 | Immigration New Zealand Migration Data Explorer R1 (Figure.NZ 공개 렌더링) |

## 한 줄 결과

이란 국적자의 뉴질랜드 **전체** 거주비자 승인 수와 같은 해 Yahoo `CL=F` 실현변동성을 비교한 2016–2023년 8개 연도에서 `r=-0.389`이었다. 이는 작고 현재 빈티지인 연간 표본의 설명적 값이며, 원 가설을 검증하거나 예측력을 뜻하지 않는다.

## 사용한 공개 집계

Figure.NZ 표는 이민청 Migration Data Explorer의 R1 Residence Visa Decisions 2025를 출처로 표시하며, 이란 국적·승인·전체 유형의 연간 값을 2016–2025로 제공한다. 이민청은 개인정보 보호를 위해 총계를 임의 반올림할 수 있고, 2022년 처리시스템 전환·2021 Resident Visa 관련 조정도 있었다고 설명한다.

| 구간 | 값 |
| --- | --- |
| IS | 2016–2023, n=8, Pearson `r=-0.389` |
| OOS | 2024–2025, n=2 — 상관계수 미계산 |
| 가격 | 같은 연도 Yahoo `CL=F` 일간 수익률의 연간 실현변동성 |

## 왜 통과가 아닌가

1. **대상 불일치**: 전체 거주비자 승인이지 투자이민·고액자산가·이민법률 리테이너가 아니다.
2. **시간 불일치**: 데이터셋의 현재 릴리스는 2026년 1월이다. 과거 연도별 최초 공개시각·빈티지가 없어 예측 시계열로 안전하게 정렬할 수 없다.
3. **표본 부족**: IS 8개 연도, OOS 2개 연도다. OOS를 계산하거나 연간 상관으로 신호를 선택하지 않는다.
4. **교란**: 코로나 국경제한, 2021 Resident Visa, 처리시스템 전환, 이민정책이 승인 건수에 직접 영향을 준다.

## 결론

무료로 접근 가능한 집계 하나는 확보했지만, 007의 핵심 행동을 측정하지 못했고 음의 동년 설명적 상관도 관계를 지지하지 않는다. 007은 복수 제공자의 비식별·사전 공표된 신규 유료 상담/투자이민 퍼널 집계 없이는 HOLD다.
