# 2026-09-08 — Cushing 현장 활동 관측: 4개 입력 조합 게이트
## 질문

쿠싱의 실제 현장 활동을 서로 다른 공개 흔적으로 확인할 수 있는가. 후보는 도시권 야간광, 도시 숙박세, 인근 대형차 통행, 공식 EIA 쿠싱 재고다.

이 문서는 WTI 가격 예측이나 단일 점수 개발 보고서가 아니다. 각 입력이 실제로 무엇을 관측하고, 어느 단계에서 조합 자격을 얻는지만 기록한다.

## 고정 원칙

1. 개별 관측값을 먼저 확보·시각화한다.
2. `observed_at`, `published_at`, `retrieved_at`, `signal_ready_at`을 복원할 수 없으면 가격·재고 검정에 넣지 않는다.
3. EIA 재고는 활동 프록시가 아니라 별도 물리 상태다. 활동점수에 중복해서 합산하지 않는다.
4. 결측 프록시를 WTI 가격, 거래량, 수익률, 임의 계절성 또는 합성 난수로 대체하지 않는다.

## 1. 도시권 야간광

| 게이트 | 결과 |
| --- | --- |
| 데이터를 구할 수 있는가 | 예. World Bank Light Every Night 월간 VIIRS COG. |
| 의도한 관측을 할 수 있는가 | 부분적으로만. 쿠싱 도심 고정 5×5 픽셀의 도시권 밝기이며, 개별 모텔·객실 점유·현장 인력을 식별하지 못한다. |
| 실제 표본 | 2015-01~2023-12 Suomi-NPP 월간 패널. 2023년 1~6월의 공개 관측값은 091 카드의 `data-sample-2023.md`에 보관. |
| 독립 검정 | 월말+45일 이용 가능 계약으로 이후 28일 EIA 재고 순변화 `r=+.053`, p=.607, n=96; 절대 주간변화 평균 `r=+.068`, p=.508. |
| 결론 | 관측판에는 유지하되, 재고 변화를 설명하는 조합 입력에서는 제외. |

## 2. 호텔/모텔세

| 게이트 | 결과 |
| --- | --- |
| 데이터를 구할 수 있는가 | 부분적으로 예. 시의 공식 2023년 9월 보고서에 2023년 5~7월 월별 수납액이 있다. |
| 실제 표본 | 2023년 5월 $7,460.20, 6월 $7,433.66, 7월 $6,088.32. 2023/24 예산서는 2020/21 $80,983, 2021/22 $87,969의 연간 실제치를 보인다. |
| 의도한 관측을 할 수 있는가 | 도시 전체의 과세 숙박수입이라는 후행 집계까지 가능. 객실 점유율·석유 작업자 비중·개별 모텔 활동은 불가. |
| 독립 검정 | 불가. 현재 원문으로 재현 가능한 표본이 너무 짧고, 과거 월별 원문·세율 변경 이력·최초 공개일이 없다. |
| 결론 | 관측 후보로 보류. 장기 월별 원문과 공개시점이 확보되기 전에는 점수·상관·조합에 넣지 않는다. |

공식 표본의 출처는 City of Cushing [2023년 9월 City Manager Report](https://www.cityofcushing.com/sites/g/files/vyhlif4306/f/agendas/cm_report_september_23_final_.pdf) 및 [FY23/24 budget](https://www.cityofcushing.com/financecity-clerk-department/files/budgetfinal2324)이다. 전자는 월별 수납 시점이 아닌 보고서에 표시된 세금월을 적은 것이므로 `published_at`과 구분해야 한다.

## 3. 인근 대형차 통행

| 게이트 | 결과 |
| --- | --- |
| 데이터를 구할 수 있는가 | 소스 수준에서는 예. ODOT `AADT_Network` 공식 FeatureServer가 AADT 연도, AADT, 이전 AADT, 단일·콤비네이션 트럭 비율 필드를 공개한다. |
| 실제 쿠싱 수치 표본 | 아직 없음. 이 실행 환경에서 ArcGIS 조회가 인증 오류로 실패했고, 대체 데이터셋을 만들거나 값을 추정하지 않았다. |
| 의도한 관측을 할 수 있는가 | 부분적. AADT 보간 네트워크와 트럭 비율은 연간 도로 활동의 근사치일 뿐, 유조차·원유 화물·실시간 현장 이동을 식별하지 않는다. |
| 독립 검정 | 불가. 쿠싱 근접 고정 구간의 장기 수치 및 해당 연도 공개일이 확보되지 않았다. |
| 결론 | 보류. ODOT가 제공하는 공식 수치를 파일로 확보한 뒤에만 개별 시각화한다. |

공식 서비스 설명은 [ODOT AADT FeatureServer](https://services6.arcgis.com/RBtoEUQ2lmN0K3GY/ArcGIS/rest/services/AADT_Network/FeatureServer)에서 확인했다. 서비스는 이를 *current interpolated counts*라 명시하고, raw count-site 자료가 별도라고 설명한다.

## 4. EIA 쿠싱 재고

| 게이트 | 결과 |
| --- | --- |
| 데이터를 구할 수 있는가 | 예. EIA 주간 쿠싱 원유 재고(전략비축 제외). |
| 의도한 관측을 할 수 있는가 | 예. 쿠싱 저장 재고라는 물리 상태를 직접 관측한다. |
| 조합 역할 | 활동 입력의 성능을 비교할 타깃 또는 별도 상태 패널. 야간광·숙박세·통행과 같은 ‘활동 프록시’로 평균내지 않는다. |

## 조합 판정

**조합 실행: 하지 않음.**

실제 장기 패널로 통과한 독립 활동 관측은 야간광 하나뿐이며, 그 입력도 EIA 재고와 관계가 없었다. 숙박세는 표본·공개시점이 부족하고, 대형차 통행은 쿠싱 수치 표본 자체를 아직 확보하지 못했다. 네 입력을 하나의 점수로 만들면 결측치를 임의 처리하거나 검정되지 않은 변수로 대체해야 한다.

### 재개 조건

1. 호텔/모텔세: **최소 60개월**의 원문 월별 수납액, 세율 이력, 각 보고서의 게시일.
2. 대형차: 쿠싱 근접의 **사전 고정 도로구간** 장기 트럭 수치, 트럭 정의, 관측·공개일.
3. 재개 뒤에도 먼저 두 관측을 **각자** 시각화하고, 계절조정·공개 지연 계약을 고정한 독립 검정을 한다.
4. 두 독립 검정의 측정 적합성과 해석 가능한 관계가 확인될 때에만 최대 2~3개 입력을 제한적으로 결합한다. 결측은 0·가격·합성 변수로 대체하지 않는다.

## 합성 CBI 문서에 대한 감사

기존 `2026-09-08-cushing-busy-index-ml-dl-validation.md`는 실제 EIA·숙박·도로 관측 패널이 아니라, WTI 가격·거래량에서 만든 특성과 코드 안에서 생성한 `cushing_busy_true` 합성 타깃을 사용한다. 해당 문서의 높은 R²는 실제 쿠싱 관측 검정이 아니며, 이 연구의 증거로 사용하지 않는다. 원문은 재현·감사 목적상 보존하되 **무효화된 합성 실험**으로 취급한다.
