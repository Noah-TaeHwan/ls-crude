# 첫 실행 프롬프트 — 설치와 현재 상태 확인

아래 블록을 ZIP과 함께 작업 AI에게 전달한다. 레포 경로를 알고 있는 환경에서는 자동 확인하고, 모르면 GitHub 연결/작업 폴더를 먼저 조회한다. 조사로 찾을 수 없을 때만 경로를 질문한다.

```text
첨부한 LS_CRUDE_CAI_AI_EXECUTION_KIT_v06.zip을 사용해
Noah-TaeHwan/ls-crude의 CAI 웹 개편 작업 환경을 준비해.

1. 실제 레포/작업 폴더와 루트·작업 경로의 AGENTS.md를 먼저 확인해.
2. ZIP의 docs/cai/execution/을 같은 레포 경로에 설치해.
   기존 파일이 있으면 비교하고, 다른 내용은 덮어쓰지 말고 충돌을 보고해.
   루트 README·AGENTS·기존 tasks.json과 앱 코드는 아직 바꾸지 마.
3. docs/cai/execution/START_HERE.md와 CORE_RULES.md를 읽어.
4. BOOT-01 카드에 따라 현재 브랜치·HEAD·변경 파일·실제 도구·기존 작업 원장을 확인해.
   기획서의 SHA나 배포 상태를 현재 사실로 간주하지 마.
5. 확인 가능한 내용을 실제로 점검하고 BOOT-01 결과를 남겨.
   읽기 전용 GitHub 연결뿐이면 설치/로컬 검사를 했다고 하지 말고 확인 범위를 분리해.
6. 선행조건과 승인을 대조해 다음 실행 단위 하나와 수정 파일을 추천하고 멈춰.

이번 승인 범위는 문서 설치와 점검뿐이야.
커밋·push·PR·병합·배포·권한 변경·원자료 수집·모델 학습은 승인하지 않았어.
결과는 상태 / 확인 근거 / 설치·변경 파일 / 미확인 사항 / 다음 실행 단위로 보고해.
```
