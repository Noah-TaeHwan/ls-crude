# 프로젝트 핵심 맥락

LS CRUDE는 팀명, 제품명은 **쿠싱 액티비티 인덱스(CAI)**다. 공개 활동 신호를 합친 지수를 보여주고, WTI의 다음 기간 방향에 추가 정보가 되는지 연구한다.

화면은 기존 React Router 앱 안에 **대시보드 / 연구·검증 / 히스토리**. 홈에는 CAI 계기판·추이, 다음 기간 상승/하락·보합, WTI 가격만 우선 둔다. 구성 영역과 긴 검증 설명은 CAI란?에 접는다. 숫자 곁의 가상/미학습/지연 상태는 숨기지 않는다. 날짜는 연월일·ISO 주차와 거래일 기준 기간이다.

기존 CFAM, Busy Board, 수박·제주·항만 등의 자료는 삭제하지 않는다. CFAM 고정 비중/캐시 점수는 학습된 CAI가 아니다. 새 CAI 성분은 명시된 manifest로만 채택한다.

CAI 점수는 확률이 아니다. 실제 0과 결측(null)은 다르다. 권한 있는 실제 run이 없으면 홈의 점수/확률은 —. 가상 73.3·64.2는 테스트/분리 데모에서만 사용한다. 학습·OOS·운영 배포는 각각 별도 완료 증거가 필요하다.

이 문서의 코드 근거는 기획서 v0.5의 과거 스냅샷 `cecf1cf`다. 현재 HEAD/운영 버전/CI/팀 합의는 BOOT-01에서 다시 확인한다. 확인하지 않은 원자료·프리뷰·회원 권한·기여율을 추정하지 않는다.
