# UI-05.S2c — 홈과 세 메뉴를 새 CAI 구조로 연결

기존 원장 연결: **UI-05.S2**. catalog 등록은 착수/완료 승인이 아니다.

홈과 세 메뉴를 새 CAI 구조로 연결를 한 변경 단위로 수행한다. 다른 카드의 작업을 함께 끝내려고 범위를 늘리지 않는다.

## 입력·출력 / 실행 결정
현재 소스와 명시된 원장/계약만 입력으로 사용한다. 출력은 카드의 수용 조건을 충족하는 변경과 실제 실행 증거다.

## 실행 순서
1. history와 구주소 호환의 선행 검수 결과를 확인한다.
2. 홈에는 CAI/예측/WTI 세 핵심 영역만 남기는 렌더 검사를 먼저 만든다.
3. 기존 WTI loader/차트와 CAI 공개 adapter를 조합한다. 한 데이터 오류가 다른 영역을 비우지 않게 한다.
4. 기존 ResearchSample 호출·비CAI 네트워크 읽기는 history에서 동작 확인 후 홈에서 제거한다. 원본 파일은 삭제하지 않는다.
5. 헤더를 작은 LS CRUDE + 세 메뉴로 바꾸고 h1/meta는 쿠싱 액티비티 인덱스로 맞춘다. build·skip link 유지.
6. 타입/빌드/등록 테스트/브라우저를 검사하고 폰트·날짜·빈 상태·WTI 동작을 대사한다.

## 필수 회귀·인계
현행 package.json/CI에서 해당 영역의 명령을 직접 확인한다. 코드 변경은 관련 테스트와 typecheck/build, UI 변경은 승인된 브라우저 검수를 추가한다. 기존 실패·새 실패·도구 차단을 구분한다. 문서/읽기 작업은 관련 경로·숫자·인용·미실행 상태를 대사한다.
수용 조건별 PASS/FAIL/NOT_RUN, 실제 명령/cwd/exit, 변경 diff, 남은 승인/의존성, 다음 카드 하나를 RESULT에 적는다. 실행자는 REVIEW에서 멈춘다.

## 중단 조건
승인 부재, 필수 입력/소스 미접근, 허용 범위 밖 변경, 연구 규칙·공개 정책 충돌은 BLOCKED. 확인된 구현 결함은 REVISION. 모든 결과를 얻기 위해 로그/스크린샷/값을 만들어 채우지 않는다.
