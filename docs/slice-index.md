# 오일 슬라이스 — 공개 신호

펜타곤 피자 인덱스는 피자 매출이 아닙니다. 공개된 주문 급증을 활동의 간접 신호로 봅니다.

오일 슬라이스(Oil Slice)도 원유 호가가 아닙니다. 인베스팅닷컴 헤드라인에서 호르무즈와 미국 인플레/정책이 갑자기 붐비는지를 **공개 신호**로 봅니다.

| 펜타곤 피자 인덱스 | 오일 슬라이스 |
| --- | --- |
| 공개 주문 급증 (매출 집계 아님) | 인베스팅닷컴 원유·매크로 헤드라인 |
| 활동의 간접 신호 | 호르무즈·유조선 헤드라인 급증 |
| 준비·긴장 | 공급 충격 / 해협 리스크 |
| (비교군) 일상 수요 | 연준·CPI 헤드라인 (수요·달러 방향) |

계산은 `ls_crude.features.slice_index.oil_slice`에 있습니다. Slice는 비교군 초안입니다. 실험 기록은 [`docs/experiments/`](experiments/README.md). 조사는 [`research/notebooks/pizza-hunt.md`](../research/notebooks/pizza-hunt.md).
