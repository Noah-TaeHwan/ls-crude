## 주제 선정 이유

원유 선물은 가격 흐름뿐 아니라 재고, 달러, 변동성, 지정학적 사건 등 여러 요인의 영향을 받습니다.

정통 원유·시장 데이터로 기본 롱숏 전략을 만들고, 펜타곤 피자 지수처럼 시장 변화를 간접적으로 보여주는 참신한 데이터 후보를 직접 찾아 시험하여 **예측력과 성과가 실제로 개선되는지** 확인하는 것이 목표입니다.

## 프로젝트 목표

1. 정통 데이터 기반 WTI 원유 선물 롱·중립·숏 기준모형 구축
2. 다양한 비정형 데이터 후보의 수집·전처리·활용 가능성 시험
3. 기준모형과 대안 데이터 추가모형의 예측력·성과 비교
4. Walk-forward 백테스트를 통한 수익성과 위험 검증

## 분석 방법

### 데이터 구축

- WTI 선물 OHLCV·거래량
- RSI·변동성 등 기본 지표
- 확보 가능한 재고·만기구조 데이터를 보조 변수로 활용

### 대안 데이터 탐색

공개 데이터 후보를 여러 개 시험하고, 시점 정합성·결측률·해석 가능성을 비교합니다.

후보 예시:

- 지정학 뉴스량
- 유조선 흐름
- 인터넷 관심도

### 모델 비교

규칙 기반 및 Random Forest 기준모형을 만든 뒤, 대안 데이터 후보를 하나씩 추가하여 개선 효과를 확인합니다.

### 백테스트

Walk-forward 방식으로 롱·중립·숏 포지션을 평가하고 다음 지표를 비교합니다.

- 수익률
- Sharpe Ratio
- MDD
- 적중률

최종 검증 구간은 후보 선정 후 **한 번만** 사용합니다.
