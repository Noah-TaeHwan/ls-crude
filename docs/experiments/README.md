# 실험 기록

피자인덱스처럼 **한 종류의 열기**만 남긴다. 전 세계 피자 매출(온체인 히트맵, 뉴스 전체)은 후보가 아니다.

타겟은 유가(`CL=F`). 찾을 피자는 크립토의 **뭐** × 뉴스의 **무슨**. 없으면 없다고 쓴다.

## 한 장에 적을 것

- 가설 한 줄 (무슨 열기 → 왜 유가)
- 크립토의 뭐 / 뉴스의 무슨 (둘 다 없으면 폐기)
- 출처·라이선스
- look-ahead 여부
- 인샘플만 봤는지 (`2015-01-01`~`2023-12-31`)
- 살림 / 보류 / 폐기
