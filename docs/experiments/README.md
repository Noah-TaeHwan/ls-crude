# 실험 기록

이 폴더에는 동료 검토 뒤 승격된 실험을 보존합니다. 신규 연구 운영 기준은 [방법론](../research-methodology.md)과 [검정 규약](../testing-protocol.md)입니다. 승격은 성과 통과를 뜻하지 않습니다.

신규 연구의 타깃은 Yahoo WTI 선물 CL=F입니다. 실제 활동·민감 맥락·WTI 연결 가설을 기록합니다. 특정 피자/크립토/뉴스 조합은 필수가 아닙니다.

| 구분 | 위치 |
| --- | --- |
| 이 폴더 | 승격된 후보 한 장씩. 가설·look-ahead·아웃샘플 미사용 |
| 수집 규칙 | [`research/INTAKE.md`](../../research/INTAKE.md) — 덤프·노트는 여기로 오지 않음 |
| 한 장 노트 | [`research/gathering/notes/`](../../research/gathering/notes/README.md) |
| 작업 표 | [신규 후보 원장](../../research/candidates/ledger.csv) |
| 원천 시드 | `research/data/pizza/` (덤프는 `research/gathering/raw/`) |
| 공개 신호 초안 | [`000-oil-slice-draft.md`](000-oil-slice-draft.md) — 비교군. 최종 후보 아님 |

파일 이름: `NNN-짧은-슬러그.md`. 승격 시 기존 파일을 확인해 다음 빈 번호를 사용합니다. 000–006 이력은 보존하며 이번 setup에서는 새 실험을 만들지 않습니다.

## 한 장에 적을 것

- 가설 한 줄 (무슨 공개 신호 → 왜 유가)
- 실제 활동 / 민감 맥락 / WTI 연결 / 대리변수의 한계
- 출처·라이선스
- look-ahead 여부
- 인샘플만 봤는지 (`2015-01-01`~`2023-12-31`)
- 살림 / 보류 / 폐기
