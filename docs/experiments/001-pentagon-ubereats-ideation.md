# 펜타곤 우버이츠 인덱스 (Pentagon Uber Eats Index)

**제안일**: 2026-09-02  
**상태**: 아이디어 평가 단계

## 핵심 가설

중동 미군 기지의 우버이츠 주문량 ↑ = 
- 기지 주둔 규모 증가 OR 기지 활동도 상승
- 중동 정세 긴장 → 미군 배치 강화 → 원유가 상승

## 팩터 설계

```
pentagon_uber_index = sum(
    uber_orders_at_base_X 
    for X in [Qatar, UAE, Saudi Arabia, Kuwait, Bahrain, ...중동 주요 기지]
)
pentagon_z = 20일 롤링 z-score(pentagon_uber_index)
```

## 실행 가능성 분석

### ✅ 장점
1. **창의성**: 펜타곤 피자처럼 unconventional하고 재미있음
2. **신호 신선도**: 거의 실시간 행동 데이터 (뉴스보다 빠름)
3. **메커니즘 명확**: 군 배치 ↔ 유가 연관성이 경제학적으로 타당
4. **구분성**: Oil Slice의 "뉴스/정책" 데이터와 완전히 다른 소스

### ⚠️ 핵심 도전과제

#### 1. 데이터 수집 (가장 중요)
- 우버이츠가 미군 기지 단위로 공개 데이터 제공? → **가능성 낮음**
- 대안:
  - Uber의 공개 API 활용 (지역 주문 집계 가능?)
  - 웹 스크래핑 (Uber Eats 모바일 앱)
  - 제3자 데이터 공급업체 (SimilarWeb, Apptopia 같은)
  - 각 기지 근처의 Uber Eats 주문 집계 (우회)

#### 2. 역사적 데이터 (인샘플)
- 2015-01-01 이전 우버이츠 데이터 수집 가능?
- 우버이츠 성장 초기(2010년대 중반)에 충분한 거래량 있었나?

#### 3. 기지 식별
- 각 기지 좌표 + 반경 X km 내 주문 할당?
- 기지마다 우버이츠 주문 특성 다름 (규모, 인터넷 접근도 등)

#### 4. 통제 필요
- 단순 "우버이츠 주문 증가" = 인플레이션, 계절성, 앱 성장 효과도 포함
- 주변 비기지 지역과 비교 필요
