날짜: 2026-09-01  
상태: **메모**. 확정 규칙이 아니다. 확정 규칙은 [`research-design.md`](research-design.md)다.

이 문서는 팀 계획 → 원유+슬라이스 → SBHNews 형태 → 크립토 맵 제안까지, 대화에서 나온 그림을 한곳에 모은다.

## 1. 이미 고정된 한 줄

원유 기본(야후 가격 + RSI) + 뉴스 서사(인베스팅담컴) + **오일 슬라이스 한 스푼**.

| 층 | 내용 |
| --- | --- |
| 가격 | Yahoo Finance `CL=F`, 인샘플 2015–2023, 아웃샘플 2024~ |
| 기본 지표 | RSI(14). 대시보드 오버레이일 뿐, ML이 아님 |
| 서사 | Investing.com CSV가 정본. 스크래핑 금지. 호르무즈·미국 인플레/정책 |
| 한 스푼 | Oil Slice = 피자인덱스 비유. 호가가 아니라 부업 열기 |
| 화면 | AI 스킬이 메인 입구, 대시보드는 그 결과를 보여주는 면 |
| 검증 | 인샘플에서만 튜닝. 아웃샘플은 후보 확정 후 한 번 |

피자 대응:

| 피자 | 오일 슬라이스 |
| --- | --- |
| 피자 가게 | 인베스팅담컴 원유·매크로 헤드라인 |
| 늦은 밤 대량 주문 | 호르무즈·유조선 헤드라인 급증 |
| 작전 준비 | 공급 충격 / 해협 리스크 |
| 평일 점심 | 연준·CPI (수요·달러 방향) |

```text
slice_score = 2 * hormuz_count + 1 * inflation_count
slice_z     = 20일 롤링 z (거래일 달력, 주말 뉴스는 다음 세션)
```

## 2. 나중에 엎고 싶은 제품 이미지

레퍼런스: [SBHNews](https://www.sbhnews.com)

SBHNews가 하는 일:

- 분쟁·시사 OSINT
- **지도 + 속보 + 시장 해석**을 한 화면에
- 사건을 고립된 헤드라인이 아니라 공간·시간·시장으로 연결

SBHNews가 **하지 않는** 일:

- 비트코인 트랜잭션 월드맵
- 온체인 히트맵으로 원유를 맞추기

가져올 것은 크립토가 아니라 **화면 문법**이다. 기사 스크래핑은 하지 않는다.

원유에 옮기면 맵의 점은 원래 지리 상품과 맞는다. 호르무즈, 홍해, 이란, 워싱턴(연준/CPI).

## 3. 추가로 나온 아이디어 (미확정)

```text
지도에서 크립토 트랜잭션이 많이 일어나는 곳
+ 실시간 뉴스
= 원유 선물 가격과의 상관
→ 알파를 찾고 백테스트 결과를 웹 대시보드로
```

매력:

- 지도는 발표·웹뷰로 한눈에 들어온다
- 뉴스와 대안 데이터를 겹치면 “한 스푼” 스토리가 강해 보인다
- 상관 → 알파 → 백테스트 순서는 연구 순서와 같다

구멍:

- 체인에는 국가가 없다. 맵 좌표는 노드 IP·거래소 클러스터·벤더 추정이고 VPN/OTC에 왜곡된다
- “트랜잭션이 많다 → WTI가 움직인다”는 메커니즘이 비어 있다. 리스크온/오프, 달러 유동성, 제재 회피는 **서로 다른 변수**다
- 실시간 맵 + 온체인 + 예측 사이트는 2주 스프린트·현 데이터 약속(Yahoo + Investing CSV)과 안 맞는다
- 대시보드를 먼저 만들면, 상관 없는 레이어가 있어 보여서 살아남는다

## 4. 세 갈래 (아직 고르지 않음)

### A. SBH의 형태, LS CRUDE의 내용 (추천 후보)

맵 = Investing.com으로 태깅한 호르무즈/홍해/이란/연준 핀  
히트 = Oil Slice  
옆 = Yahoo 종가·RSI·뉴스  
아래 = RSI vs RSI+Slice 인샘플 백테스트  

피자 한 스푼이 지도가 된다. 연구 설계와 충돌하지 않는다.

### B. 크립토는 맵이 아니라 숫자 한 줄

메커니즘이 있는 시계열만. 예: BTC 변동성, 달러 스테이블코인, 이란/제재 크립토 뉴스 태그.  
DXY/CPI 통제 후 WTI 잔차와 **인샘플 상관만** 보고, 죽으면 폐기. 아웃샘플은 열지 않는다.

### C. SBH 클론 + 온체인 히트맵 + 원유 예측 사이트

발표용으로는 화려하다. 2주 안에 정직하게 검증하기 어렵다. 비추천 후보.
