## 승인 구분

- 문서 연결 승인: 본 REP-01 범위(로컬 문서 세팅). 팀 합의 대기.
- 연구 승인(방향·역할·공개 범위): 미확인.
- 게시 승인(학습·운영 게시): 미확인.
- `docs/cai/PRD.md`는 존재하지 않는다. 정상 링크처럼 두지 않으며,
  PRD 제정은 별도 합의 사항이다.
