성찬님, 오늘 같이 진행할 작업을 GitHub에 정리했습니다.

전체 흐름은 **① 아이디어 모으기 → ② 쿠싱 관련 후보 선별 → ③ 실제 자료 확인·수집 → ④ 전처리 → ⑤ 지수 구성·모델 학습·평가 → ⑥ 결과 검토·대시보드 연결**입니다.

현재 100여 개 자료에서 후보·보조자료 33개를 정리했습니다. 그중 교통량·DMR 유량 2개는 전처리와 실험까지 확인했고, 추가 5개는 표본만 있는 상태입니다. 나머지는 접근·과거 이력 확인 등이 필요해서 33개 전부 수집 완료는 아닙니다.

가능하시면 **5번 공항 활동, 11번 숙박세, 16번 판매·사용세**를 이 순서로 봐주실 수 있을까요? 같은 정의의 과거 자료를 구할 수 있는지 확인하고, 가능하면 **4단계 전처리까지** 부탁드립니다. 어려운 후보는 어디서 왜 막혔는지만 남겨주셔도 됩니다. 이 분담이 가능한지도 알려주세요.

저는 기존 교통·유량 입력과 공통 프로그램·결과 취합을 맡고, SPP 전력 자료는 재접속도 실패하여 보류했습니다. 기존 DMR의 2023년 자료를 새로 수집·전처리해 기존 입력과 일치하는 것은 확인했습니다.

시작 안내에 **33개 상태표, 담당 단계별 AI 프롬프트, 전처리 규격, Python 실행 명령, GitHub 제출 방법**을 연결했습니다. 이미 준비된 교통·유량 입력으로 먼저 같은 실험을 맞추고, 새 자료가 준비되면 별도 설정으로 비교하면 좋겠습니다. 입력 CSV는 Git에 없으니 확보 여부부터 확인 부탁드립니다.

**저도 성찬님도 같은 프로그램으로 하시면 됩니다.** `cai_team.py check`로 입력을 확인하고, 공통 학습 엔진의 `run --no-cache`로 실행한 뒤, `cai_team.py package`로 검증된 결과 묶음을 만듭니다. 명령은 시작 안내에서 그대로 따라갈 수 있습니다.

각자 실행한 결과는 안내의 검증 도구로 묶어서 자기 브랜치/PR로 올리면 됩니다. 먼저 두 결과를 같은 조건인지 확인해 나란히 비교하고, 월요일에는 검토된 결과를 대시보드에 연결해 설명과 화면을 정리하면 좋겠습니다.
