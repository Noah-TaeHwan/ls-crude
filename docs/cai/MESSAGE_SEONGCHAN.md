# 성찬님께 보낼 답장 — 미발송

성찬님, 보내주신 파일 2개 확인했습니다. Python 파일 해시도 메모와 일치하고, 공항 4행·숙박세 36개월·사용세 24개월·판매세 일부가 코드에 들어 있는 것을 확인했습니다.

코드를 검토하다가 가중치 학습 부분에서 수정할 점을 찾았습니다. 현재 월별 표본은 내부 학습 20행·검증 10행 조건에 부족한데, 목적함수가 모두 같은 실패값을 반환하면서 초기 50:50이 학습 결과로 저장됩니다. 분류모델 실행과 별개로, 이 50:50은 최적화된 조합 가중치로 해석하기 어려워 보입니다.

검수본에서는 표본이 부족하면 학습 차단으로 표시하고, 그 모델의 가중치·성능값을 저장하지 않도록 수정했습니다. 정답을 계산하는 마지막 날짜가 학습 종료일을 넘지 않도록 하는 검사도 넣었습니다. 이 기준으로 원래 월별 일정에 남는 학습 행은 11개라 성분 최소 12개 조건도 부족합니다. 기준은 임의로 낮추지 않았습니다.

코드는 합성 데이터로 검증했습니다. 보내주신 데이터와 기존 결과는 그대로 보존했고, 실제 월별 실험을 다시 돌리거나 우리 일별 결과에 합치지는 않았습니다.

이어서 대조할 수 있도록 숙박세·사용세·공항의 원본 PDF와 표 페이지, 판매세 충돌 행의 원표를 보내주실 수 있을까요? 가능하면 원본 실행의 ALL_IN_ONE_RESULT.json, model_run/result.json, model_comparison.csv, weights.csv와 환경 버전도 함께 부탁드립니다. 시청 옛 PDF 링크 일부가 새 홈페이지로 이동해서 원본 파일이 있으면 도움이 됩니다.

원문과 시점부터 맞춘 다음, 기존 일별 공통 실험과 외부 월별 실험을 구분해서 다음 실행 범위를 정하면 좋겠습니다.

별도로 기존 교통·유량을 고정 50:50으로 결합한 실험용 CAI v0.1을 대시보드에 연결했습니다. 2023-12-29 기준의 과거 지수이며, 보내주신 후보는 원문 검토 뒤 별도로 판단하겠습니다.
