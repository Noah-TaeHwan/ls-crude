# CAI 진행 현황과 제출 마무리

기록 기준: 2026-09-14. **실험용 CAI v0.1과 대시보드는 공개됐고, 결과보고서 표현 정정·수정본 대조·최종 제출은 남아 있습니다.** 새 수집·학습을 이번 마무리 완료 조건으로 추가하지 않습니다.

## 지금의 결론

교통량과 South STP 신고 유량으로 과거 활동 대리 지수와 대시보드를 구현했습니다. 2023-12-29 기준 CAI는 43.1점이며 현재 활동이나 유가 상승 확률이 아닙니다. 별도 일별 회고 예측 실험에서 CAI 추가에 따른 개선은 확인하지 못했습니다. 성찬님 월별 실험과 기존 일별 결과는 섞지 않습니다.

수집·작업 상태의 정본은 [33개 작업표](CANDIDATE_WORKLIST.md)와 연결된 후보 JSON입니다. 위 표는 기록 기준일의 요약입니다. 모델 비교는 [연구 브리프](RESEARCH_BRIEF.md), 지수 정의는 [v0.1 산식·재현](../../research/indexes/cai-v0.1/README.md)을 따릅니다.

## 제출 전에 남은 작업

| 담당 | 남은 일 | 완료 기준 |
| --- | --- | --- |
| 성찬 | 결과보고서 표현 정정 | RF·Walk-forward·거래성과·최종 OOS를 확인된 범위로 정정. 유량 의미·선별 기준·제외 이유·기준일 정리 |
| 성찬 | 원표·기존 월별 실행 결과 보유 여부 회신 | PDF·표 페이지·판매세 충돌 근거·결과 JSON/CSV·환경 버전 전달, 없으면 미보존 명시 |
| 태환 | 수정본과 웹·요약의 최종 대조 | 수정본 수신 후 숫자·기간·알고리즘·역할·완료 상태 일치 확인 |
| 공동 | 최종 확인과 제출 | 최종 문서 버전 합의, 시연 링크 확인, 제출 완료 확인. 현재 제출 완료로 표시하지 않음 |

원문 파일을 받지 못해도 그 한계를 명시한 v0.1 발표·공유는 가능합니다. 자료 수신 전 원문 검증 완료나 월별 성능 재현 완료로 바꾸지 않습니다. 이 문서는 제출 대행·메시지 발송의 완료 기록이 아닙니다.

## 보고서에서 고칠 핵심

- RF·Walk-forward 계획을 실제 실행 완료 문장으로 쓰지 않습니다. CAI 자체는 고정 50:50 지수입니다. 별도 일별 예측 실험은 상승률 기준선 1개와 로지스틱 모델 5개를 비교한 고정 시간분할 평가입니다. 별도 전략 실행이 있으면 코드·설정·결과를 별도 근거로 연결합니다.
- “최종 검증 구간 한 번 사용” 대신 최종 OOS 미실행을 명시합니다. 성찬님이 보고한 2024–2025 월별 결과를 미열람 최종 OOS로 간주하지 않습니다.
- South STP는 월중 일최대 신고 방류유량이며 도시 전체 실사용 수량·원유 펌핑량이 아닙니다.
- 두 자료의 사용이 무료 지속성·활동 대표성·최초 공개시점까지 모두 입증했다는 뜻은 아닙니다.
- 공항의 짧은 이력, 세금 자료와 기존 학습기간의 불일치, 판매세 충돌값을 구분합니다. 오래된 9월 8일 비고와 역할표도 최종 문서 기준으로 대조합니다.

[성찬님께 보낼 짧은 피드백](MESSAGE_SEONGCHAN.md). 파일 요청의 방향은 **성찬님이 수집·실행에 사용한 자료를 태환에게 전달**하는 것입니다. 태환 측 일별 코드·설정·지수 근거는 이미 [공동 시작 안내](TEAM_START_HERE.md)에 연결했습니다.

## 발표·공유 순서

1. [대시보드](https://ls-crude.vercel.app/)에서 CAI와 과거 기준일을 먼저 보여줍니다.
2. [연구 기록](https://ls-crude.vercel.app/research)의 106 → 33 → 2 흐름과 제출 검토 자료를 구분합니다.
3. 50:50 산식·날짜 선택·공백을 설명하고, 일별 6개 모델의 검증 결론을 제시합니다.
4. 미완료 사항을 후속 과제로 밝힙니다. [발표·공유용 요약](https://ls-crude.vercel.app/cai-research-brief.html)에 5분 설명 순서가 있습니다.

## 이번 마무리 이후의 연구

교통량 2021–2022 공백 보강, 성찬 자료 원문 대조, 관측·공개·개정 시점 확인, 실제 활동 대표성 분석, 현재 날짜로 갱신하는 경로와 독립 예측 검증입니다. 추가 수집이나 새 모델 결과를 확보한 것처럼 발표하지 않습니다.
