## 결과 해석의 한계

- RF·Walk-forward 계획을 실제 실행 완료 문장으로 쓰지 않습니다. CAI 자체는 고정 50:50 지수입니다. 별도 일별 예측 실험은 상승률 기준선 1개와 로지스틱 모델 5개를 비교한 고정 시간분할 평가입니다. 거래성과는 별도 실행 근거 없이 주장하지 않습니다.
- 최종 OOS는 미실행입니다. 성찬님이 보고한 2024–2025 월별 결과를 미열람 최종 OOS로 간주하지 않습니다.
- South STP는 월중 일최대 신고 방류유량이며 도시 전체 실사용 수량·원유 펌핑량이 아닙니다.
- 두 자료의 사용이 무료 지속성·활동 대표성·최초 공개시점까지 모두 입증했다는 뜻은 아닙니다.
- 공항의 짧은 이력, 세금 자료와 기존 학습기간의 불일치, 판매세 충돌값을 구분합니다. 자료 수신 전 원문 검증 완료나 월별 성능 재현 완료로 바꾸지 않습니다.

## 보존·후속 연구

교통량 2021–2022 공백 보강, 성찬 자료 원문 대조, 관측·공개·개정 시점 확인, 실제 활동 대표성 분석, 현재 날짜로 갱신하는 경로와 독립 예측 검증은 후속 연구입니다. 별도 요청 전 새 수집·학습·최종 OOS를 실행하지 않습니다.

기존 자동갱신·배포 설정은 이번 종료 정리에서 변경하지 않습니다. 프로젝트 종료를 서비스 중단이나 예약 작업 해제 지시로 해석하지 않습니다. 기존 실험·기각·차단 기록과 원장 개별 상태는 보존합니다.
