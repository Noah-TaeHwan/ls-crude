# 세션/모델 교체 인계

1. 현재 unit/parent와 승인된 작업 범위.
2. base SHA, 실제 브랜치, 미커밋 변경 목록.
3. 지금까지 바꾼 파일과 확정된 인터페이스.
4. 실제 실행한 검사·exit·결과·증거 경로.
5. FAIL/NOT_RUN과 가장 최근 오류 원문 요약.
6. 이미 시도한 수정 2개 이내와 각각의 관측 결과.
7. 유지할 사용자 변경·금지 파일·연구/게시 승인 상태.
8. 다음 실행할 행동 한 가지와 확인할 기대값.

새 AI는 이 인계만 신뢰하지 않고 핵심 파일/검사 상태를 다시 확인한다. 긴 대화의 복사보다 현재 변경 상태와 오류 재현을 넘긴다.
