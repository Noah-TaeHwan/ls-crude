CAI는 쿠싱의 활동 신호를 0–100점으로 합성한 제안 지수입니다. 점수는 활동 신호의 수준이며, 유가 상승 확률이 아닙니다.

선정 기준과 중복 처리펼치기접기

실제 채택 전에 쿠싱과의 공간적 연결, 주간 이력, 공개 시점, 수집 권한, 결측률을 확인합니다. 같은 활동을 여러 번 측정한 신호는 중복 비중을 피하도록 묶거나 제외합니다.

10개는 이 목업의 입력 수일 뿐, 확보 목표나 확보 실적이 아닙니다. 실제 지수의 n은 검증 후 채택한 신호 수입니다. 재고·날씨·WTI 스프레드 등은 활동 데이터와 구분한 별도 예측 입력 또는 통제 변수로 검토합니다.

가중치와 머신러닝의 역할펼치기접기

관측용 CAI · 먼저 만드는 기준선

10개 활동 점수에 각각 10%를 적용합니다. 사람이 정한 규칙이므로 이 계산 자체는 머신러닝이 아닙니다.

CAI = Σ(wᵢ × sᵢ)
wᵢ ≥ 0, Σwᵢ = 1
초기값: wᵢ = 1 / n

학습형 가중치 · 검증할 확장안

과거 입력과 정답으로 오차를 줄이는 비중을 학습할 수 있습니다. 합계 100%와 비음수 조건은 우리가 별도로 설계하는 제약입니다.

활동 점수 + 학습 목표
→ 데이터 기반 가중치 추정
→ 이후 구간에서 동일 비중과 비교

무엇을 맞힐지가 먼저입니다. WTI 방향을 정답으로 사용해 비중을 최적화했다면, 그 버전은 순수한 도시 활동 수준보다 예측용 지수(CAI · 학습 가중치)로 구분하는 편이 명확합니다. 일반 회귀 계수나 변수 중요도가 곧바로 “합계 100%의 구성 비중”인 것은 아닙니다.

현재 표시된 확률은 어떻게 계산했나요?펼치기접기

대시보드의 64.2%는 학습된 결과가 아니라 가상 로지스틱 공식을 계산한 값입니다.

z = −2.60 + 0.04 × 73.3 − 0.50 × (−0.5)
P(상승) = 100 / (1 + e−z) ≈ 64.2%

CAI는 10개 가상 점수의 평균이며, 재고 변화 −0.5백만 배럴과 모든 계수는 예시입니다. 활동 증가가 상승 확률을 높인다는 부호도 가정일 뿐입니다. 실제 모델의 방향·크기·확률 신뢰성은 별도 검증해야 합니다.

지수 구성 비중과 예측 공식의 계수는 다른 파라미터입니다. 학습을 실제로 실행할 때는 정답과 목표 함수, 학습·검증 구간부터 정합니다.

히스토리

기존 연구, 방향 전환, 버전 변경과 근거. 보관 기록은 현재 지수의 구성·성능으로 합산하지 않습니다.

점수 옆 ‘가상’, 확률 옆 ‘미학습’ 표시는 숨기지 않습니다. 게이지 색은 활동 척도이며 공포·탐욕이나 매매 추천을 뜻하지 않습니다.

한 제품 CAI 안에서 동일 가중치 / 학습 가중치 버전을 구분합니다. 학습·선택은 개발 구간에서 하고, 최종 OOS로 우승 조합을 고르지 않습니다.
