# 주말 공동 실험 제안 (성찬님용 초안 — 발송하지 않음)

## 제안 요약

쿠싱 활동 지수(CAI) 실험을 주말에 두 사람이 같은 기준으로 나눠 실행하자는 제안입니다.
역할 수락 전이므로 아래는 **제안**이며, 수락 여부와 역할은 성찬님이 정합니다.
태환 측 승인된 작업(TMAS 확대·프로그램·배포)은 이와 별개로 이미 진행했습니다.

## 제안 역할 (수락 시)

- 태환: TMAS 확대·기준 지수·제품 연결·배포.
- 성찬: 입력 시점·측정 정의·학습 가중치·반증 검토.

## 공유 기준 (양쪽 동일해야 함)

| 항목 | 값 |
| --- | --- |
| 입력 manifest/hash | config의 `price.sha256` 등 pin, provenance에 기록 |
| 타깃 | 다음 5거래일 WTI 상승(2분류, 보합=하락) |
| 학습/내부검증 | 2015-01-01..2023-12-31 안에서 train_end 2020-12-31, val 2021-01-01..2023-12-31 |
| 성분 순서 | config `components` 순서 고정(현재 없음) |
| 전처리 | 학습 구간 한정 z-clip(컴포넌트), StandardScaler(시장) |
| 평가 | log_loss 주지표, accuracy·brier, 같은 평가 날짜·타깃 |
| 설정 목록 | weekend_shared / weekend_taehwan / weekend_seongchan |
| 코드 버전 | cai-exp/0.1.0, 코드 해시는 provenance에 기록 |

## 날짜 분할 금지

두 사람이 기간을 반씩 잘라 서로 다른 자료로 경쟁하지 않습니다. **같은 shared config를
각자 실행**해 재현성을 먼저 확인하고, 이후 담당 묶음만 추가 실행합니다.

## 현재 상태 (성찬님 실행 시)

- CAI 두 모델은 적격 컴포넌트가 없어 `blocked`로 나오는 것이 정상입니다.
  (TMAS 2023 12개월은 확보했지만 공개시각 규칙 미확정, LAUE 약관 미확인.)
- 따라서 성찬님 묶음은 "실행 가능하지만 blocked 사유가 기록되는" 상태로 시작합니다.
- 컴포넌트 적격성이 확정되면 같은 config에 pin하고 즉시 해제됩니다.

실행 명령은 같은 폴더의 `COMMANDS.md`를 그대로 복사해 쓰시면 됩니다.
