# 다음 작업 프롬프트

BOOT 결과를 읽은 뒤 사용한다. 구체 작업 ID를 사용자가 따로 쓰면 그것이 우선이다. 추천이 여러 개이면 아래 선택 규칙으로 하나만 고르고, 승인 근거가 없으면 해당 코드 수정은 하지 않는다.

```text
앞선 BOOT-01 결과와 docs/cai/execution/START_HERE.md를 기준으로 이어서 진행해.
기존 원장의 상태·선행조건·승인이 실제로 확인된 실행 단위 중,
직전 인계에서 추천한 첫 작업 하나를 선택해.
그 단위의 문서/로컬 코드 수정과 테스트만 승인한다.
연구 목적·타깃·가중치 규약 변경이나 실제 학습·수집·OOS 평가는 승인하지 않는다.

make_packet.py --task <선택한 실제 ID>로 패킷을 만들거나 해당 카드를 직접 읽고,
EXECUTOR_PROMPT.md에 따라 구현→검증→RESULT 기록까지 진행해.
한 작업을 REVIEW로 인계하면 멈춰. 전체 프로젝트를 한 번에 수행하지 마.
선행조건이 안 맞으면 무엇이 부족한지와 안전하게 할 수 있는 읽기 작업 하나를 보고해.
커밋·push·PR·병합·배포는 하지 마.
```

`<선택한 실제 ID>`는 AI가 catalog와 직전 보고에서 확인하여 치환하는 런타임 값이다. 사용자가 태스크 경로를 외워 입력할 필요는 없다. 후보 task의 카드 존재를 완료/승인으로 간주하지 않는다.
