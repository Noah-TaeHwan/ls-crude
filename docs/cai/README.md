## 제품 목적 한 문단

쿠싱의 현장 활동을 무료 공개 자료로 재는 **쿠싱 액티비티 인덱스(CAI)** 를 만들고,
지수와 WTI 다음 주 움직임의 관계를 사전등록·동결된 절차로 검정해 웹 대시보드로 보여준다.
성공 기준은 수익 예측이 아니라 과정의 일관성이다.
