## 11. 함정 (이미 밟았던 것들)

- TMAS 월별 파서: zsh 배열은 1-based라 월 매핑이 한 달씩 밀린 적 있음 → `OK MM YY.VOL` 파일명으로 검증할 것.
- `series.shift(n)`은 **행 이동**이지 달력일 이동이 아님 — 월별 자료에서 치명적. `align_availability()` 사용.
- pandas CSV 기본 줄바꿈(`\r\n`) vs pandas(`\n`) — 해시 비교 전 `lineterminator="\n"` 고정.
- DMR은 같은 날짜를 덮는 관측이 2개 있으면 최신 1회만 사용. 월별 85개 관측이 1,758개 행으로 반복 사용됨 — 독립 관측 수와 행 수를 혼동 금지.
- 학습 가중치 [0,1]은 허용된 경계값이지 코드 오류가 아님. `market_cai_learned`의 가중치는 CAI 단독 손실로 학습됨(공동 최적화 아님).
- `preregistered_at` 같은 선언 시각은 파일 mtime과 대조해야 함 — 선언이 실행보다 늦은 오기가 있었음(회고 탐색으로 분류).
- Vercel Preview/Production은 SSO 보호라 curl 302가 정상. 내용 확인은 소유자 브라우저 세션으로.
- GitHub Actions 실패(수초 내 종료·로그 없음)는 코드 실패가 아니라 결제 한도. 로컬 검증으로 대체하되 원격 CI PASS로 주장하지 말 것.
