# WTI 변동성 Evidence Brief 설계

## 목적

LS CRUDE는 유가의 방향을 맞히는 서비스가 아니다. 최근 완료된 Yahoo Finance `CL=F` 일봉으로 WTI가 얼마나 크게 움직이는지 보여주고, 그 움직임을 먼저 설명할 공개 신호를 찾는 과정을 공개한다.

## 화면 계약

### WTI 관측

- 메인 게이지는 최근 5거래일 연환산 실현변동성의 백분위만 표시한다.
- 백분위 기준 분포는 `2015-01-01`~`2023-12-31`로 고정한다.
- 점수 구간은 `0–24 안정`, `25–49 보통`, `50–74 고조`, `75–100 급변`이다.
- 가격 방향, RSI, Oil Slice, 검증 전 대안 신호를 게이지에 섞지 않는다.
- 기준일, 마지막 확인 시각, 출처, 산식, 최근 5일·20일 실현변동성, 신선도 상태를 텍스트로 함께 제공한다.
- `CL=F`는 연속선물이며 롤 갭을 포함할 수 있다고 명시한다.
- 일봉이므로 `실시간` 대신 `최근 완료 세션 기준`이라고 쓴다.

### 연구 장부

- `/research`는 48개 후보와 통과 0개라는 현재 정본을 숨기지 않는다.
- 대표 행은 가설, 확보 데이터, 인샘플, 아웃샘플, 판정을 함께 보여준다.
- 홈에는 최근 연구 기록과 작성자, 날짜, 원문 링크를 보여준다.
- `미검증`, `보류`, `기각`, `별도 전략`을 성과처럼 포장하지 않는다.
- 연구 절차는 `가설 → 데이터 적격성 → 인샘플 → 규칙 동결 → 한 번의 아웃샘플`로 표시한다.
- `/backtest` GET은 `/research`로 영구 이동하고, POST는 실행 엔진이 없다는 거절을 유지한다.

## 데이터 계약

최근 시장 관측치는 연구용 `baseline-snapshot.json`과 분리한 `wti-market-snapshot.json`에 둔다.

- 수익률: `r_t = Close_t / Close_(t-1) - 1`
- N일 연환산 실현변동성: `100 × sqrt((252 / N) × sum(r_t²))`
- 점수: `100 × count(reference_rv5 <= current_rv5) / reference_count`
- 로그수익률은 2020-04-20의 음수 `CL=F` 종가 때문에 쓰지 않는다.
- 생성 시 New York의 오늘 날짜보다 앞선 일봉만 완료된 봉으로 인정한다.
- 생성 실패 시 마지막 정상 JSON을 덮어쓰지 않는다.
- 앱은 마지막 확인이 36시간을 넘거나 마지막 일봉이 4일을 넘으면 `stale`로 표시한다.

## 갱신 계약

- 평일 `06:30 UTC`에 Yahoo `CL=F` 일봉을 다시 받고 스냅샷을 만든다.
- 자동화는 같은 작업 안에서 연구 테스트, 앱 타입 검사, 빌드를 통과한 데이터만 PR로 병합한다.
- 자동화가 실패하면 기존 배포를 유지한다.
- 저장소의 `GitHub Actions가 PR 생성·승인 가능` 설정은 실제 실행 전에 저장소 범위에서 활성화해야 한다. 기본 토큰 권한은 계속 읽기 전용으로 둔다.
- 공개 화면은 자동화 성공 전까지 현재 체크인 스냅샷과 신선도 상태를 정직하게 보여준다.

## 완료 기준

- 게이지 바늘과 0–100 값이 같은 백분위를 나타낸다.
- 값이 없으면 임의 위치에 주차하지 않고 `데이터 없음`을 표시한다.
- `/`, `/research`, `/backtest` 이동 경로가 서버 빌드에서 검증된다.
- 홈과 연구 화면에 각각 하나의 H1과 논리적인 H2 구조가 있다.
- 키보드 포커스, 색 외 상태 텍스트, `prefers-reduced-motion`을 확인한다.
- README와 공개 UI 한국어는 수치·고유명사·상태값을 보존한 채 imnotai 게이트를 통과한다.
- 로컬 테스트, 브라우저, PR CI, Preview, Production을 서로 다른 증거로 확인한다.
