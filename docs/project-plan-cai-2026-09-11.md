# LS CRUDE — CAI 트랙 기획서

기준일 **2026-09-11 KST** · 발표 마감 **2026-09-15 09:00 KST** · 초안(사용자 요청으로 AI 작성) · **성찬 합의 대기 항목 있음**

이 문서는 [09-10 방향 한 장](research-direction-2026-09-10.md)의 후속이자 **CAI(쿠싱 액티비티 인덱스) 트랙의 현행 기획**이다. 09-10 문서는 이력으로 보존한다. 충돌하는 두 규칙 — "점수 없음이 결론", "WTI 예측 금지" — 은 이 문서가 대체한다. 단, 팀(성찬) 합의 전이므로 합의 결과에 따라 수정한다.

## 1. 목적 한 줄

펜타곤 피자 인덱스의 질문 구조(**현장 활동 → 공개 관측 → 시장 관계**)를 따라, 쿠싱의 활동을 무료 공개 데이터로 재는 **CAI**를 만들고, 그 지수와 WTI 다음 주 움직임의 관계를 **사전등록·동결된 절차**로 검정해 웹 대시보드로 보여준다.

성공 기준은 "수익 예측"이 아니라 **과정의 일관성**이다.

> 왜 이 자인가 → 무엇을 구했나 → 어떻게 쟀나 → 무엇이 나왔나 → 무엇이 아직 미검증인가

## 4. 방법 — 사전등록 규약

[검정 규약](testing-protocol.md)을 그대로 따르며, 아래를 실행 전에 고정한다.

| 항목 | 고정 내용(제안) |
| --- | --- |
| 주 타깃 | 다음 `h=5`거래일 WTI 방향 (상승 vs 하락·보합). 보조: 수익률, RV |
| 구성 후보 | D0 인벤토리에서 확정. **3–5개**, 각 구성의 가설 방향 사전 명시 |
| 정렬·결측 | as-of 정렬. 결측은 채우지 않음(0 포함 금지). 주기 혼합 금지 |
| 가중치 학습 | IS **2015-01-01~2021-12-31**에서만. NNLS/ridge/로지스틱 등 소수 파라미터 모델. 변환은 학습 구간만 적합 |
| 조합 선택 | IS 내부 검증 **2022-01-01~2023-12-31**에서만. 무작위 행 분할 금지 |
| 동결 | 명세·코드 해시·동결 시각 기록 후 변경 금지 |
| OOS | 2024-01-01~동결한 마지막 완료 Yahoo 날짜. **1회, 보고용**. 선택·튜닝에 사용 금지 |
| 불확실성 | HAC 또는 block bootstrap, permutation, family 기록 |
| placebo | 최소 1개(무관 지역·가짜 사건일·시프트 대조 중) |
| 문구 | "예측기"가 아니라 "관계 실험". 확률에는 불확실성·표본·한계를 함께 표시 |

기존 2024+ 결과가 이미 열람된 후보는 `SEEN`으로 기록하고, 그 결과를 선택에 사용하지 않는다.

## 5. 데이터 계획

**원칙: 인벤토리 먼저, 헌트는 부족분만.**

- **이미 확보(재사용)**: 쿠싱 보드 레인 30여 개 — EIA 주간/월간 재고, 위키 조회(일), KUSH(월), QSR 라벨(신규 수집 도구 있음), 숙박세, AADT(연), LAUS(월), 날씨(Mesonet·KCUH), USGS, 규제·사고 로그 등. 상세는 [보드 프로그램](../research/programs/cushing-busy/PROGRAM.md) 참조.
- **헌트(신규)**: 일·주 단위 현장 활동 후보. 예: 주유 판매, 상수도·폐기물, 도로 일별 교통, 공항 운영, 소매·판매세 월별, 식당 관련 공개 집계. 출처 후보: 시·주 정부 공개 포털, 연방 통계, Wikimedia, EIA, Mesonet.
- **수집가능성 판정 기준**: 무료·공개 / 이용 조건 명확 / 역사 2015년 이전 포함 / 주기(일·주 우선, 월 허용) / 단위·지역 정의 명확 / 이야기 연결 가능.
- **D1 게이트**: 주간 정렬 가능한 성분이 **3개 이상**이면 주간 CAI, 미만이면 월간 CAI로 낮춘다. **그림을 위해 주기를 지어내지 않는다.**
- 막힌 후보는 사유·해제 조건과 함께 원장에 남긴다(기존 방식).

## 9. 완료 판정 (09-15에 "충분")

- CAI 정의서·가중치·동결 기록이 있어 다른 사람이 같은 입력으로 재현할 수 있다.
- WTI 관계는 사전등록된 절차와 결과·한계가 연결되고, OOS는 1회만 사용됐다.
- 좋은 결과든 나쁜 결과든, 막힌 후보와 실패도 기록에 남아 있다.
- 두 팀원 중 다른 사람이 근거 경로를 따라 설명할 수 있다.
- 대시보드의 모든 숫자는 실제 자료·산출물과 대조되어 있다(가상 수치 없음).
