# WTI 비교 검정 규약

이 규약은 활동 proxy의 **재현 가능성과 WTI와의 관계**를 평가합니다. 이번 설정 작업은 데이터 수집·지수 검정·알파 발견 완료를 뜻하지 않습니다. [방법론](research-methodology.md)과 [후보 기록](recording-standard.md)에 실행 전 명세와 실행 후 증거를 남깁니다.

## 1. “증거”의 수준

| 수준 | 필요한 증거 | 주장 가능한 범위 |
| --- | --- | --- |
| `E0` | 가설·활동/맥락 연결·검색 계획 | 아이디어/아직 조사 중 |
| `E1` | 원 제공자·접근 시도·권리/커버리지 확인 기록 | 확인된 접근 가능성 또는 특정 차단 사유 |
| `E2` | 원본 영수증·해시, 정제 코드, 지수 명세·산출물, 재현 절차 | 해당 자료로 이 지수를 구성할 수 있음 |
| `E3` | 타깃·기간·전 변형과 검정 결과·품질 점검·동료 검토 기록 | 명시한 표본의 탐색적 관계 또는 무관계 |
| `E4` | 실행 전 동결 증거, 미열람 독립 구간, 한 번의 평가·재현·동료 검토 | 고정한 가설의 독립 검증 결과; 음성 결과도 포함 |

높은 단계는 아래 단계의 증거를 요구합니다. 단계는 효과 크기·인과성의 등급이 아니며 `E4`도 알파나 인과를 자동 입증하지 않습니다. 접근 불가가 확인된 후보는 `E1/PARK` 또는 `E1/KILL`로 완결될 수 있습니다. URL·스크린샷·다른 사람의 요약만으로 수집/재현 단계로 올리지 않습니다.

## 2. 실행 전 동결표

후보 기록에 작성 시각과 검토자를 남기고 다음을 고정합니다. 각 수정에는 버전과 이유가 필요합니다.

| 항목 | 고정 내용 |
| --- | --- |
| 가설·주 타깃 | 방향 수익률/달러 변화/미래 변동성 중 하나, 기대 관계 또는 방향 미정 |
| 데이터·지수 | 출처·빈티지·기간·단위·빈도·지역·산식·가중치·품질/결측 규칙 |
| 시점 | 신호 `available_at`, 의사결정 cutoff·시간대, WTI 거래일 결합 방법 |
| 검정 | 주 검정 하나, 보조 검정, lag/horizon 전체 목록, 사건 정의·창·통제/placebo |
| 분할 | 학습/내부 검증 날짜, 표본 종료, 경계 purge, OOS 열람 여부·관련 기존 결과 |
| 판정 | 실무적으로 의미 있는 효과·커버리지/표본 최소 조건·중단 조건·다음 결정 |
| 추론 | 불확실성 추정 방법, 다중검정 family와 보정법, 시도 횟수 집계 범위 |

공통 `r` 합격값이나 모든 자료에 동일한 표본 수를 강제하지 않습니다. 예상 빈도·독립 관측/사건 수에 맞춰 기준을 사전 명시합니다. 기준 없이 먼저 본 결과는 탐색으로 기록하고 사전등록했다고 소급하지 않습니다.

## 3. 시간 분할과 이미 본 OOS

- 선택·변환 적합·특징/가중치/lag 탐색: **2015-01-01~2023-12-31**의 실제 공통 가용 구간만 사용합니다. 2019 시작 원천을 2015까지 채워 넣지 않습니다.
- 내부 검증: 시간순 expanding/rolling split을 위 인샘플 안에서 미리 고정합니다. 무작위 행 분할은 금지합니다. 각 fold 변환은 학습 부분만 적합합니다.
- `h`거래일 미래 타깃이면 타깃 종료일이 학습 경계를 넘는 학습 행을 제거합니다. IS 검정에는 2024년 가격이 들어가는 말단 타깃도 포함하지 않습니다. 동일 사건·겹치는 타깃이 경계를 공유하지 않도록 필요한 gap을 기록합니다.
- 독립 평가: **2024-01-01~동결한 마지막 완료 Yahoo 날짜**. 후보/변형·타깃·규칙·명세/코드 해시와 동결시각을 남긴 뒤 한 번만 엽니다. 결과 후 튜닝·재선택에 사용하지 않습니다.

**이 저장소 전체의 2024+가 미열람이라는 주장은 금지합니다.** [기존 HHE 노트](../research/gathering/notes/2026-09-07-hidden-hydrocarbon-exposure-test.md)와 [Wikipedia 검정 노트](../research/gathering/notes/2026-09-07-wikipedia-factor-validation.md)에는 이미 2024+ 결과가 있습니다. 이 링크는 노출 사실의 기록이며 해당 결과를 이번에 재검증했다는 뜻이 아닙니다.

후보마다 `oos_exposure`를 `UNSEEN / SEEN / UNKNOWN`으로 기록하고 누가·언제·어떤 후보/변형·기간·결과를 보았는지 연결합니다. 관련 결과가 선택에 영향을 주었거나 영향 여부가 불명확하면 `SEEN/UNKNOWN`: 기존 2024+ 결과는 **탐색적 재사용**이며 `E4`가 아닙니다. 이름 변경·재동결·경계 이동으로 미열람성을 복구할 수 없습니다.

그 경우 새 명세를 고정하고 아직 보지 않은 향후 관측 구간을 별도 prospective 검증으로 예약합니다. 표본 확보 전에는 `PARK`, `E3 이하`, `독립 검증 미실행`입니다. 최근에만 존재해 2015–2023 교집합이 없는 원천도 접근·구성 시연은 가능하지만, 2024+로 후보를 선택하며 이 규약의 OOS 검증이라고 부르지 않습니다. 마감 때문에 독립 기간을 만들어내지 않습니다.

## 4. WTI 목표와 lag의 정확한 뜻

`P_t`는 Yahoo `CL=F`의 완료된 일봉 `Close`, `t`는 WTI 거래일입니다. 다운로드 옵션은 기존 [yahoo.py](../research/src/ls_crude/data/yahoo.py)의 `interval="1d", auto_adjust=True`를 기록합니다. 일봉 날짜는 발표시각의 증거가 아니며, 지수의 실제 이용가능시각을 별도로 검증합니다.

| 목표 | 명세와 해석 |
| --- | --- |
| 다음 `h`거래일 수익률 | `F_h(t) = P_(t+h) / P_t - 1`; 신호는 `t`의 고정 cutoff 전에 이용 가능해야 함 |
| 다음 `h`거래일 달러 변화 | `D_h(t) = P_(t+h) - P_t`, 단위 USD/bbl; 수익률과 혼용하지 않음 |
| 다음 `h`거래일 RV | `100 × sqrt((252/h) × Σ[j=1..h] r_(t+j)^2)`, `r_t=P_t/P_(t-1)-1`; % 연환산 RMS 변동성 |
| lag 곡선 | `corr(I_t, r_(t+k))`; `k>0`이면 지수가 이후 WTI 수익률을 앞섬, `k=0` 동행, `k<0` WTI가 앞섬 |

RV 타깃에는 **신호일 수익률 `r_t`를 포함하지 않습니다**. 현재 시장 카드의 [realized_volatility](../research/src/ls_crude/market_snapshot.py)는 과거창 함수라 그 출력 그대로를 미래 타깃이라고 쓰면 안 됩니다. `h=1/5/20` 등을 사용한다면 선택한 값과 보조 값 전부를 먼저 고정합니다. 저빈도 원천에는 같은 lag 표기를 원천 주기와 WTI 거래일로 각각 밝혀야 합니다.

선물 자료의 0·음수 가격, 분모 0, 극단 변화, 계약 교체/롤 관련 불연속 가능성을 검사합니다. 원본을 삭제·클리핑하지 않습니다. 기본 수익률/RV 분석은 계산에 필요한 가격 중 하나라도 비양수이거나 누락된 창을 제외하고, 날짜·이유·제외 전후 `n`을 보고합니다. 로그수익률을 비양수 가격에 적용하지 않습니다.

사전 지정한 달러 변화 민감도 분석에는 해당 구간을 보존해 비교할 수 있습니다. 유리한 결과를 얻기 위해 제외 규칙을 바꾸지 않습니다. Yahoo 연속선물 수익률을 거래 가능한 개별 계약의 롤·비용 반영 PnL로 해석하지 않습니다.

## 5. 누수 금지와 반증

| 위험 | 실행 전/후 확인 |
| --- | --- |
| 같은 날 자료 | `available_at < decision_cutoff`; 공개가 늦으면 다음 허용 세션으로 이동 |
| 지연·개정 | 관측일/공개일/가용일/수집일 구분, 빈티지 또는 보수적 계약 증거; 없으면 `NOT_PROVEN as-of-safe` |
| 미래 기준 | 전체 기간 평균·분산·분위수·최종 구성종목·미래 방향을 라벨/정제에 사용 금지 |
| 보간 | backward fill·미래 관측치로 선형 보간 금지; 이월은 공개 이후·지정 유효기간만 |
| 사건 선택 | WTI 급등일을 보고 “신호 사건”을 고르지 않음; 외생 사건·기준·전체 사건 목록 고정 |
| 반복 시도 | 실패한 출처·바스켓·변환·lag·horizon·타깃·사건창도 시험 family에 기록 |

주 검정은 Pearson 또는 Spearman 등 가설에 맞게 고정하고 기간·빈도·유효 쌍 수를 보고합니다. 비정상적 수준 시계열의 단순 상관은 기술통계로만 제시하고 변화/추세 처리와 계절성·기존 WTI 정보로 설명되는지를 확인합니다.

미래 RV처럼 창이 겹치거나 자기상관이 있으면 단순 독립 표본 p-value·무작위 행 bootstrap으로 유의성을 주장하지 않습니다. HAC 또는 시계열 block bootstrap 등 방법·lag/block 길이·seed를 사전에 정하고, 최소한 겹치지 않는 관측으로 민감도를 확인합니다. 구현/표본이 부족하면 기술적 상관과 `추론 미검증`만 보고합니다.

시차·변형을 여러 개 보면 전체 family의 raw p와 보정값(예: BH-FDR)을 함께 기록합니다. family 규모를 파악하지 못하면 보정된 발견이라고 주장하지 않습니다. 같은 기간의 사후 통제·추가 변형 결과도 탐색으로 표시합니다.

최소 하나의 메커니즘 관련 placebo/반증을 계획합니다: 무관한 지역·동일 서비스의 비교집단, 미리 지정한 가짜 사건일, 시간구조를 보존하는 블록/시프트 대조 등. 음의 lag는 역방향 단서일 뿐 독립적인 인과 검증이 아닙니다. 적절한 대조를 확보하지 못하면 이유와 잔여 혼동을 남깁니다. 사건 연구는 사건 수·중복창·다른 동시 충격을 보여주며 인과 실험이라고 부르지 않습니다.

## 6. 상태별 최소 표·그림

| 상태 | 필수 제출물 |
| --- | --- |
| 모든 후보 | 활동/맥락·출처/접근/권리·기간/빈도·담당·판정·다음 행동 표; 검색 경계·실패 이력 |
| 자료 확보 | coverage/결측/제외·가용 지연 표, 실제 관측 지수 시계열 그림(단위·지역·기간·표본 경계 표시) |
| WTI 검정 실행 | 주 타깃 scatter 또는 시계열 비교, 사전등록 lag 곡선/표 전체, 주/보조/placebo 결과 표(`n`, 효과, 불확실성, 보정, 구간) |
| 사건 검정 실행 | 사건 목록·창·겹침·통제 표와 사건 전후 그림; 해당 없으면 `N/A — 이유` |
| 기각/차단/미실행 | 판정 이유와 영수증 링크, 미확보 자료·해제 조건·다음 날짜. 실행하지 않은 검정만 `NOT_RUN/N/A`; 검정 후 기각이면 `RUN`과 실제 N·결과·한계를 보존 |

실측값이 없으면 빈 데이터 차트나 합성 시계열을 실측 결과처럼 만들지 않습니다. 시연용 예시는 `EXAMPLES ONLY`로 표시하고 실제 장부/성과 집계에서 제외합니다. 차트의 이중축·정규화는 원 단위와 변환 규칙을 공개하고 크기가 다른 시계열을 같은 효과처럼 보이게 하지 않습니다.

## 7. 재현 영수증과 검토

`research/indexes/<id>/`의 영수증에 실행 ID·UTC 시각·작성자/검토자, 입력·출력 경로/해시, 실제 명령·작업 디렉터리·환경, 코드/명세 버전, split·노출 상태, 경고·오류를 기록합니다. 새 분석은 `research/notebooks/<id>/`의 실제 파일과 실행 명령을 연결합니다. 아직 없는 실행기를 있는 것처럼 적지 않습니다.

기존 시간 분할·위키 정렬 구현의 좁은 회귀 확인은 다음과 같습니다. 환경은 [로컬 설정](local-backtest.md)을 따릅니다.

```bash
cd research
.venv/bin/python -m pytest tests/test_splits.py tests/test_wiki_pageviews_asof.py
```

이 테스트 통과는 해당 구현의 회귀 증거이며 **새 후보의 as-of 정확성·통계적 유효성·데이터 확보 증거가 아닙니다**. `python -m ls_crude.build`는 최신 구간을 수집하고 앱 스냅샷도 수정하므로 후보 검정의 기본 명령으로 사용하지 않습니다.

동료는 실제 파일과 명령의 연결, 경계 누수·노출 상태, 전 변형 공개, 표/그림과 판정의 일치를 확인합니다. 결과가 재현되지 않으면 주장 범위를 낮추고 문제·수정·재검토를 남깁니다. `KEEP/KILL/PARK`는 연구 결정이며, 검정 수준과 “무엇이 아직 미검증인가”를 별도로 함께 발표합니다.
