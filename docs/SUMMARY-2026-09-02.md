## 🚀 구현 로드맵 (우선순위)

### Phase 1️⃣: 즉시 (1-2주)

#### P1-1: Wholesale-Logistics 신호 구축 (1주)
- Cass Freight Index + 물류 회사 주가 (UPS, FedEx, XPO)
- 2015-2023 역사 데이터
- Oil Slice와 상관성 테스트

#### P1-2: Oil Pulse UI 프로토타입 (1주)
- React 컴포넌트: OilPulse, PulseWaveform, SignalIndicator, FactorBar
- 정적 데이터로 UI 검증
- 시간 범위/속도 조절 기능

### Phase 2️⃣: 단기 (2-4주)

#### P2-1: Granger Causality 검증 (1주)
- Wholesale-Logistics → Oil 선행성 측정
- 최적 lag 결정 (0, 5, 10, 20, 30일)

#### P2-2: Whale Index 평가 (2주)
- Glassnode/CryptoQuant API 연동
- CoinEx 고래 신호 추적
- 유가와의 상관성 검증

#### P2-3: Oil Pulse 인터랙션 (1주)
- 시간 범위 선택 (1D/1W/1M)
- 민감도/속도 조절
- 팩터 클릭 → 상세 정보 팝업

### Phase 3️⃣: 중기 (4-8주)

#### P3-1: Financial Demand ML 구축 (4주)
- yfinance로 재무제표 수집 (대체에너지 vs 석유)
- Feature engineering (ROE, 성장률, CAPEX 강도)
- XGBoost/LSTM 모델 훈련
- Walk-forward + Monte Carlo + Bootstrap 검증

#### P3-2: Renewable Displacement 데이터 수집 (2주)
- IEA 발전량 리포트
- Investing.com 재생에너지 뉴스
- 신호 생성 및 Oil Pizza 결합

#### P3-3: Oil Pulse 데이터 통합 (2주)
- Supabase 연동 (API)
- WebSocket 실시간 업데이트
- 각 팩터별 실시간 신호 업데이트

### Phase 4️⃣: 장기 고도화 (8주+)

#### P4-1: Factor Lab 통합 (2주)
- Permutation test (전체 팩터)
- 5개 시간지평 검증
- PASS/FAIL 최종 판정

#### P4-2: 알림 & 내보내기 (1주)
- 신호 변화 실시간 알림 (웹, 이메일, 모바일)
- PNG/SVG/CSV 내보내기

#### P4-3: 모바일 & 다크/라이트 테마 (1주)
- 반응형 디자인 (모바일)
- 테마 전환 (dark/light)
