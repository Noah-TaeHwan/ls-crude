# LS CRUDE — 연구 발견 데스크

2026-09-07 · 이스트캠프 AI 퀀트 4기 · 오태환 × 손성찬

목적: 관람자가 무엇을 찾는지, 어디까지 왔는지, WTI와 어떤 가설로 연결하는지, 무엇이 남았는지를 몇 분 안에 설명할 수 있게 한다. 시각·카피·사용성의 Design 팀 검수이며, 사람을 모집한 사용자 실험이나 WCAG 인증은 아니다.

## 시각·상태 계약

- 깊은 녹색 배경, 아이보리 본문, 앰버는 선택·열린 질문, 민트는 실측 WTI에 사용한다. 상태에는 항상 문자를 붙인다.
- 헤드라인·상태 패널·얇은 구분선으로 위계를 만들고, 반복 pulse나 장식적인 데이터 모양을 만들지 않는다.
- 1440px 데스크톱부터 320px 좁은 화면까지 핵심 동선을 확인한다. Reduced motion과 강제 색상 모드를 고려한다.
- 내비게이션 로딩은 React Router의 실제 진행 상태로 안내한다. 가짜 로딩 타이머를 넣지 않는다.
- 장부 파싱 실패는 `—`와 오류 문구다. 0개로 간주하지 않는다.
- 시장 자료 없음은 연구 기록으로 이어지고, 1봉이면 가격은 보여주되 흐름은 그리지 않는다. 업데이트 지연은 마지막 관측 날짜와 이유를 보존한다.
- 후보 비교선 없음은 자료 확보 범위와 다음 조건을 설명한다. 009 검정 요약이 있어도 이 화면에 정렬된 시계열이 있다고 주장하지 않는다.
- 001 원안 철회와 001B 민간 도시권 후속 가설은 구분한다. 018은 정유 권역의 공개·역사 집계 연구다.
- 현재 RV와 신호 공개 이후 미래 RV 타깃은 다른 구간이다. 이미 본 2024–2026을 새 OOS로 다시 세지 않는다.

## 팀용 디자인 변경 기록

1. 연구 질문을 히어로로 올리고 대형 게이지를 실측 시장 맥락으로 재구성했다.
2. 두 화면의 복제된 숫자·대표 표 대신 현재 정본에서 읽는 인벤토리를 연결했다.
3. 세 가지 서로 다른 판정의 연결 가설, 전체 후보 검색, 필터 복구, 단계별 공개 근거를 추가했다.
4. 버튼·링크·공개 방법론·팀 크레딧을 하나의 시각 시스템으로 통일했다.
5. 원문보다 좁게 해석한 두 가설과 장부 오류 카피를 독립 편집 검수에서 교정했다.

## 검증과 sign-off

- 시각: PASS — UI Designer가 데스크톱 홈·장부·WTI, 모바일 홈·필터·후보 카드·브리지를 직접 확인했다.
- 카피: PASS — Visual Storyteller의 독립 편집 검수, 원문 재대조.
- 사용성: PASS — UX Researcher의 독립 과업 점검 후 메인이 같은 브라우저 동작을 재검증했다. 1440·768·390·320px 가로 넘침 없음, 후보 전환·018 정확 검색·062 검색·0건 복구·20봉·RV20 확인.
- 실제 사람 대상 사용자 실험·VoiceOver·별도 WebKit: 미검증.
- 최종 타입 검사·운영 빌드·앱 테스트 4개: PASS. 정본 파싱·오류 거부·운영 cwd·리다이렉트 경계를 확인했다.
- 로컬 운영 빌드 브라우저: 홈 hydration 오류 0, 연구 화면 runtime 오류 0. 실제 navigation loading과 404 복귀 링크 확인.
- 누락된 시장·장부 오류·실제 마지막 1봉·stale 조건을 임시 주입해 브라우저 확인 후 원본 파일과 Git diff가 같음을 검증했다.
- 서버/브라우저 ICU 차이로 AM/오전이 달라지던 초기 렌더 오류를 고정 KST 표기로 교정했다.
- 메인이 렌더 색을 다시 읽어 확인: 본문 16.11:1, 카드의 보조 본문 7.98:1, 주 버튼 9.17:1. 정확한 값은 contrast.json에 있다.
- graphify AST 갱신 완료. SQL parser 미설치 경고는 UI 코드 검증과 별개이며 해당 SQL 추출은 포함하지 못했다.
- 작업 브랜치: ux/research-discovery-desk. 위 증거는 로컬 디자인 검수 결과이며 GitHub PR·CI·머지 결과는 별도 확인한다.
